# Voice Terminal DSH 插件

一个项目内 Bundle（功能包）`@voice-terminal/dsh-plugin`，包含设备控制、桥接、项目唤醒任务、浏览器界面和影子代理预设。设备控制已向当前绑定的根代理登记七项工具，通过统一设备路由选择核心主机本机或已配对设备；代码接入及自动化覆盖不代表真实双机交互已经验收。组件职责及依赖见 [`components.json`](components.json)（组件声明），完整维护流程见[DSH 插件维护手册](../../../docs/guides/dsh-plugin-maintenance.md)。

开发构建和隔离测试产物位于项目 `.local/build/dsh`（代理宿主构建缓存）；正式应用中的插件由本体构建与安装流程打包维护，用户数据留在既有资料目录。工具名、HTTP（网络接口）路径、Loader（加载器）行标识、设置命名空间、消息来源和任务存储格式保留历史契约。

- 根入口：桥接 `voice-terminal-shadow-bridge`（语音会话桥接）。
- 子入口 `./device-control`：`voice-terminal-device-control`（已绑定根代理的设备观察、动作、终端、文件及原任务查询）。
- 子入口 `./wake-tasks`：`voice-terminal-wake-tasks`（项目唤醒任务）。
- `lib/client.js`：官方浏览器模块闭包（设置页与消息渲染）。
- `cordis.patch.yml`：三个宿主组件及 `preset-shadow-agent`（影子代理预设）的组合补丁，由构建生成。

在插件目录运行 `npm test`：执行类型检查、组件依赖检查、官方浏览器构建和回归测试。项目安装使用 `scripts/setup-dsh.ps1`；已有锁定宿主可使用 `-Offline -SkipInstall`（离线且跳过宿主依赖安装），最后用 `-Offline -ValidateOnly`（离线只校验）。

项目唤醒任务使用 `storages/voice-terminal-wake-tasks.json`（任务存储），与官方 `schedule_*`（会话调度工具）独立。已有官方 Automation（自动化）功能包选择会保留。冻结参考上下文只在 `read_wake_reference`（读取任务参考）调用时读取，不自动注入模型。

桥接协议保持 2.0；桥接工具和设备工具只用于各自已绑定的根代理。`capture_screen`（按需截屏工具）位于桥接组件，通过受鉴权接口捕获当前交互设备或明确指定设备的屏幕双图，受屏幕图像设置、设备能力和模型图片输入能力约束。终结型回执保留激活水位与幂等规则。预设保留原有默认工具、压缩、子代理和工作流能力。

## 设备工具与边界

`device_id`（设备编号）必须指向明确的执行设备；`local`（本机别名）表示运行核心服务的主机。远端目标需要已经认证的设备任务通道及对应能力；断线、代次变化或能力缺失时拒绝执行，不改投本机。

| 工具 | 当前能力 | 主要边界 |
| --- | --- | --- |
| `device_list`（设备列表） | 登记设备、连接状态、能力与活跃语音交互设备 | 从核心主机的统一设备快照读取 |
| `device_windows`（窗口清单） | 可见窗口、标题、所属程序、位置及窗口状态 | 明确选择设备，不读取窗口像素 |
| `device_observe`（界面观察） | 有界 UI Automation（界面自动化）控件树、窗口身份与内容摘要，返回 `observation_id`（观察编号） | 默认最多 100 个元素、16 层；当前工具不附像素提示；观察缓存最多 64 项，有效期 30 秒 |
| `device_control`（窗口动作） | 点击、输入、滚动、按键、移动或拖动、窗口管理、控件模式调用、批量动作 | 引用观察编号，经既有一次性审批后重新核对身份和设备代次；批量最多 32 步点击或输入 |
| `device_task_query`（原任务查询） | 查询桌面、终端和文件原任务台账 | 设备离线时仍可查询，不重新派发任务 |
| `device_terminal`（受限终端） | 创建、输入、读取增量输出、状态、取消、关闭 | 仅开放 `hostname`（主机名）、`identity`（当前账户）、`processes`（进程清单）、`network`（网络接口）四种只读命令；每条输入经过审批 |
| `device_file`（设备文件） | 列目录、读文件、将已登记的 DSH 文件附件写入设备 | 每次操作经过审批；不跟随目录链接；写入只新建，不覆盖已有目标 |

窗口管理包括最小化、最大化、还原、移动、调整大小和关闭。控件模式包括调用、切换、展开或收起、选择或取消选择、滚入视图、设置文本及数值。当前模型动作入口固定关闭 `hardware`（真实硬件输入）和 `focusFallback`（切换前台焦点回退），主要依赖控件自动化和窗口消息；依赖真实鼠标或键盘输入的应用需要另行验证。

文件目录清单最多 200 项；默认读取上限为 131072 字节，可请求最高 4294967296 字节，该值是协议上限。小文本可直接返回正文，图片和普通文件进入 DSH 附件服务；大文件使用有界流及独立 SFTP（SSH 文件传输协议）任务，核对原始长度和 SHA-256（内容摘要）。写入只接受已登记附件，并将目标路径、附件大小及摘要与审批内容绑定。结果未知时保留原任务编号，由查询工具确认，不自动重放。

## 社区来源与接入范围

设备控制选择性派生自 `pureexe/dsh-windows-remote-ssh`（社区 Windows 远程桌面插件）0.1.1，固定提交 `b640f268c1e1ee1134e6fa5b51f15736b2bab26b`。来源、原件摘要和修改范围见[上游锁定清单](../../../config/dsh/remote-ssh-upstream.lock.json)，原始 MIT（宽松开源许可证）版权与许可随包保留。

派生代码复用了观察缓存、动作复核、脱敏、文件类型判断及 Windows 常驻辅助进程。设备发现、配对、身份认证、SSH（安全外壳协议）传输和媒体通道由项目自己的局域网框架维护，工具参数不携带 SSH 密码或私钥。

底层仍保留应用枚举、独立文本及表格读取、剪贴板、进程管理、显示器与光标信息、系统通知等操作，但当前七项设备工具没有对应模型入口。应用启动受原生白名单禁止；任意 PowerShell（脚本运行环境）执行未开放；上游的等待界面条件和工具延迟加载入口也未作为当前设备工具接入。

## 运行与验收范围

当前工具的绑定、审批、观察复核、固定设备路由、任务回执及文件完整性已有自动化覆盖；辅助进程健康检查只能证明进程与受限管道可用。真实配对客户端通过 DSH 完成远端窗口观察、桌面动作、终端及附件任务，仍需端到端现场验收，不能用模拟回调或独立传输测试代替。

远程客户端的原生控制台入口已接入：经已有配对控制通道和独立本机回环入口整体转发 DSH 的 Web UI（网页界面），原生插件模块和多网页连接沿用上游实现，DSH 凭据由服务端代持。两端同步升级，控制台独立于语音监听；实现、回收及现场验收范围见[远程 DSH 原生网页转发](../../../docs/architecture/remote-dsh-console.md)。网页入口与模型实际执行设备桌面、终端及文件任务分别验收。

运行轨迹通过根代理公开实时流的 `reasoning-delta`（思考增量）及 `tool/call`、`tool/result`（工具开始与结果）回调到工作台固定单槽。`action_seq`（动作序号）统一排序思考、工具和运行状态；旧会话、旧激活及乱序动作拒收。工具仅显示名称与状态，思考正文仅留在有界界面内存中。字段、取消方式和拒收规则见 [Bridge 2.0（桥接协议）活动端点](../../../docs/architecture/bridge-2.0-protocol.md)。

| 组件 | 保留能力 |
| --- | --- |
| 设备控制 | 七项已绑定根代理的设备工具、观察缓存和常驻桌面辅助进程；按设备及连接、执行器代次隔离，沿用审批与原任务台账；真实双机交互待验收 |
| 桥接 | 上下文合并与安全门禁、旁路文字读取、按需屏幕双图捕获、进度与信息发布、提前静默、澄清、结果与无需动作终态、状态观察、会话导出与解绑 |
| 项目唤醒任务 | 规则解析、创建／查询／修改／取消、持久删除确认、旧项目任务迁移、重启恢复、冻结参考按需读取、语音事件发布 |
| 浏览器 | 官方设置表单、工作区和模型选择、推理强度、恢复提示、桥接消息渲染及语言资源 |
| 预设 | 原有官方文件、命令、后台作业、技能、子代理、网页、压缩及工作流能力 |

终态工具只在 `accepted`（接受）或 `duplicate`（已接受的重复回执）时结束回合。进度进入二等信箱；信息与终态进入普通事件路径。运行软提醒默认关闭，仅显式提供正的 `runtime_reminder_interval_ms`（运行提醒间隔毫秒数）时按间隔在下一步安全边界注入。工作区作用于新语音会话；模型与推理强度直接共用 DSH 全局配置和正式模型目录，插件不再保存或应用单独覆盖。新建语音会话读取当前全局选择，已有及恢复会话保留原选择。功能和现场验收边界见[项目隔离 DSH 控制台](../../../docs/guides/dsh-console.md)。

配置维护 `host.patch.yml`（宿主组合补丁）与 `preset/`（预设源码），构建生成一个 `cordis.patch.yml`（安装组合补丁）；不要直接修改生成产物。共享鉴权、协议、网络传输和取消作用域位于 `src/shared/`（共享目录），宿主服务使用公开依赖与类型，浏览器状态使用官方注入钩子。
