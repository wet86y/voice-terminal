# 少女声离线参考种子

此录音沿用项目在本机已配置的少女声参考素材，迁移自测试工作区的通用基底参考输入。名称中的 MiniMax（在线语音服务）表示原参考音色来源；AnifLive（本地语音）配置、转换与推理不调用在线合成。

| 属性 | 固定值 |
| --- | --- |
| 文件 | `reference.wav`（参考录音） |
| 大小 | 320044 字节 |
| SHA-256（内容摘要） | `5ff48d3254e051594bfc114a964b6b3ff1c7fd3f56f0becfe32b9f1836898699` |
| 准确转写 | 你好，这是一段用于测试流式语音生成的较长中文文本。 |
| 语言 | `zh`（中文） |

本轮仅用于用户授权的本机开发与验证。当前资料不足以确认公开再分发录音及其音色的授权，不将本地验证视为公开分发许可。公开交付前应补齐原始合成记录、相应服务条款与声音权利说明；若不能确认，应替换为已获许可的参考录音并更新固定摘要、转写及模型构建身份。

唐语歌参考录音不随源码重复保存，其固定来源、仓库修订及摘要见 `config/aniflive-presets.json`（预设输入目录）。模型及录音各自的公开分发权利需要分别核对。
