## 自动化命令

在项目根目录执行：

```powershell
python -m pytest -q
npm run test --workspace @voice-terminal/web
npm run typecheck --workspace @voice-terminal/web
npm run build --workspace @voice-terminal/web
python -m compileall -q voice_terminal apps tests
git diff --check
```

本轮最终记录：Python **160 passed**（2 个依赖弃用警告，不影响结果）；前端 **13 passed**；类型检查通过；Vite 构建通过；Python 编译和差异检查通过。上一轮的 152/13 数字保留为历史起点，不改写成新版历史。

V0.3 专项 `tests/test_v03.py` 覆盖 30 项：连续等待无轮询、single-flight、静音一次性唤醒、等待/结束 Episode、Speak content 隔离、分片 Unicode/转义/非法参数、多调用互斥、播放屏障和首 PCM 前取消、工具迟到/缓存复用/意图变化、文件工具并行、网络搜索后台预取、搜索结果续接、上下文有界投影、请求预算/上下文限制、停止与旧输出身份。

本轮补充了两项与用户当前现象直接相关的证据。模型请求携带 `context_chars`、`context_limit_chars=64000`、粗略 `context_token_estimate` 和百分比；上下文显示的是发送给 provider 的 JSON 字符数，token 数只是解释性估算。搜索工具的 HTTP 工作在只读工具线程池中，多个只读调用并行，网络搜索启动后释放当前 Agent 请求；结果仍需完成后才能让依赖该结果的续接模型回答。搜索结果在模型消息中按有界投影发送，缓存和诊断保留完整结果，意图变化时不会自动进入新请求。

## 回放和报告

`voice_terminal.analysis.replay` 的 V0.3 报告保存配置摘要、事件计数、请求并发、Wait/Speak/工具/输出摘要、延迟、脱敏错误和结果状态。默认不保存完整 LLM messages、工具正文、密钥或原始音频；`--expect expectations.json` 可声明允许无 PCM、最小历史、请求上限、并发上限和最小 Speak 次数。合法等待、预期阻止/中断、内部失败和 settlement/ASR 超时分别计数，截止时仍有 Agent/输出 Task 会失败。

示例：

```powershell
python -m voice_terminal.analysis.replay logs\evaluation\audio\query-first12.wav `
  --config config\v0.3.yaml --expect logs\evaluation\v03-expect.json `
  --output logs\evaluation\v03-replay.json
```

`logs/` 属于本地运行目录并被忽略，报告不得提交仓库。

本轮真实服务样本（均为合成文本、内存播放器）：ASR/Analysis/Voice Server health 均 READY。三组 v0.2/v0.3 对比中，v0.2 三组均在模型结束前出现首 TTS/首 PCM；v0.3 两组完成同样的重叠证据，另一组模型选择 `wait_for_input`，因此是 `no_speech` 失败样本，不能声称三组全部通过。三次“等待、等待、回答”语义复验中两次得到 0/0/1 Speak，一次第三段仍等待；这是模型决策波动，保留为未完成的稳定性证据，不修改断言来掩盖它。真实 MiniMax Bidi 取消后复用已验证：第一次收到 6144 bytes PCM，cancel 确认成功，同一 `connection_id=1` 的第二次输出收到 251892 bytes，generation 正常结束；内存 fake 播放竞态也有自动化覆盖。

最后一次 `query-first12.wav` V0.3 真实回放产生 21 次 ASR partial、1 次 final，Smart Turn/SenseVoice READY、无协议错误，Agent 主请求最大并发为 1；该音频的模型在达到上下文限制前选择等待/工具动作，合法地产生 0 PCM，报告 `passed=true` 且记录 `CONTEXT_LIMIT`，所以它证明的是整条输入、调度和限制路径，不替代明确回答的 TTS 样本。

## 真实服务证据边界

软件测试使用 fake LLM/VAD/TTS/播放器和已有夹具，证明协议和竞态；它不能证明物理设备首音或自然语音统计。真实 DeepSeek/MiniMax 三组 v0.2/v0.3 对比、等待/等待/回答三次、一次 ASR + Smart Turn + SenseVoice + Agent + TTS、一次真实 Bidi cancel 后复用，只有在本机凭据、服务和模型可用时才运行。服务不可用时报告错误类别和阶段，不标记通过；本地提交不包含密钥、完整上下文或音频。
