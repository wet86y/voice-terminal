| 业务 | 接入行为 |
| --- | --- |
| 静默等待 | 使用共享紧凑控件；前后端允许整数 5–1800 秒。滑条前半段 5–180 秒，后半段 4–30 分钟，分钟按整分钟步进。保存沿用下一次会话生效，失败恢复原值。 |
| 实际声波 | 麦克风帧和播放器真正交给输出设备的 PCM（脉冲编码音频）计算五频段音量；音频回调只保存最多 200 毫秒的最新采样，计算和发送在回调之外，每秒至多 20 帧。正式输入与播放相互独立，因此按实际播放事务选择输出音源。 |
| 音量事件 | `audio.levels`（实时音量事件）包含 `source`（输入／播放来源）、`levels`（五个 0–1 音量）及 `generation`（音频轮代）；状态提供 `audio_generation`（当前音频轮代）。拒绝旧轮代，等待／思考安静，停止、打断、断线、播放完成及超过 300 毫秒无有效帧时清零。音量不重建聊天条目。 |
| 手动任务 | `POST /api/v1/application/wake-tasks`（桌面任务创建接口）验证当前实例 Cookie（会话凭据）、Host（目标主机）和 Origin（请求来源）。宿主通过内部凭据调用受保护接口，继续委托原 DSH（代理执行宿主）存储、调度与到期投递。手动目标固定为 `shadow_agent`（后台代理），只保存说明，不冻结参考。 |
| 任务兼容 | `creation_source`（创建来源）区分 `manual`（手动）、`agent`（代理）、`unknown`（历史来源未知）；不升级旧存储格式。保留修改、取消、固定间隔与 Cron（定时表达式）。新任务使用当前时间后一小时和系统时区；分钟值提交时补零秒，已有排期的时区、秒数及毫秒保留。 |
| 声纹采集 | `capture_id`（采集请求标识）绑定一个可停止、可取消的有界麦克风流。满五秒才接受普通停止，每段默认八秒。停止注册和现场测试分别使用对应 `capture/stop`（采集停止接口）。取消、离页、重启和退出释放设备；迟到结果不能恢复已取消的状态。三段齐全且无录制时才允许保存，原音质和一致性检查继续执行。 |
| 实际资源 | 模型行常驻与提交内存使用同一真实进程快照。顶部按 PID（进程标识）及创建时间对受管进程和子进程去重；任何必要采样缺失时显示“未提供”。`commit_limit_bytes`（系统提交内存上限）来自系统性能接口。显存没有可靠应用归属指标时显示“未提供”，CPU（中央处理器）行不显示显存。 |
| 设备配置 | 分别显示未保存草稿、已保存待重启配置、实际运行设备与实际加载引擎；重试继续由原宿主管理器执行。 |
