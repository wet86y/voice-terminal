# CAM++分发升级与旧声纹组件卸载

本轮将CAM++（声纹嵌入模型）原生接入与流式准入更新正式交付到分发安装器。用户确认旧声纹档案可以删除，因此本次分发策略取代此前“旧档案只读保留”的初次功能验收边界。最新产物、摘要和验收结果见[当前交付](current-release.md)；流式行为与性能基线见[声纹功能验收](campplus-streaming-acceptance-20261012.md)。

产品显示版本继续沿用0.9.0，以构建编号标识此次更新。本地发布和分发安装器使用同一程序包。程序包内置官方中文通用CAM++ v1.0.0（权重版本）的28,036,335字节种子文件，文件摘要为 `3388cf5fd3493c9ac9c69851d8e7a8badcfb4f3dc631020c4961371646d5ada8`（SHA-256安全散列摘要）。组包和安装均校验固定内容，安装时不联网，运行时通过FunASR/PyTorch（原生模型加载与推理框架）读取外置目录中的原始权重，不使用CAM++的ONNX（模型交换格式）导出文件。

安装器与正式入口的本体安装路径执行同一原生事务：

1. 检查目标程序已停止，展开并完整校验本体和CAM++种子。
2. 在候选目录复制并读回校验官方权重，签发 `resource-install.json`（模型安装收据）。保留模型文件重新核验内容，拒绝沿用失效摘要。
3. 构建新的 `models/manifest.json`（模型总清单），同步 `app/release.json`（本体登记）中的模型构建编号与清单摘要。
4. 用 `tmp/update-transaction.json`（升级事务日志）同时管理本体换入、新声纹模型安装、旧声纹模型和旧档案删除。删除项先移入事务旧内容区，未提交失败或中断按逆序恢复。
5. 成功提交后回收旧内容。启动时按新资源清单核验模型、启动独立声纹进程，并在模型加载与首次计算预热完成后报告就绪。

| 路径或字段 | 中文含义与处理 |
|---|---|
| `app/resources/model-seeds/campplus-zh-cn-common` | 官方离线升级种子；属于固定本体 |
| `models/speaker/campplus-zh-cn-common` | 正式CAM++权重及安装收据；安装或修复后加载此目录 |
| `models/speaker/wespeaker-cnceleb-resnet34` | 旧WeSpeaker模型资源；升级成功后删除 |
| `data/speaker/wespeaker-cnceleb-resnet34` | 旧模型专属注册档案；升级成功后删除 |
| `data/speaker/registry.json`、`templates`、`probe.npy` | 旧根档案；仅在注册记录明确属于WeSpeaker时删除 |
| `data/speaker/campplus-zh-cn-common` | CAM++专属档案；升级和重装均保留 |
| `speaker_migration` | 随本体声明的声纹升级规则，固定来源与目标模型身份 |
| `delete_only` | 事务删除项；只允许固定旧模型与旧档案路径 |

未知或损坏、无法确认模型身份的根档案保留，不阻止新本体安装，也不参加CAM++评分。恢复白名单不允许删除任意用户目录或CAM++档案；路径经过工作区边界和重解析点检查。其他用户配置、会话记录、接口密钥、其他模型与运行环境均保留。旧WeSpeaker不再出现在可下载资源清单中。

本轮固定模型版本为v1.0.0。后续变更声纹权重版本须同步引擎指纹、固定摘要与原生升级规则；不能只改资源目录版本。再次安装同一程序包可修复CAM++权重，已有CAM++注册档案不删除。

没有有效CAM++档案时，程序保留筛选和主人专属打断偏好，但有效运行进入观察状态。需要重新录制三段永久主人声纹，注册后恢复原先选择。初始阈值可在高级设置调整；自动功能验收不等于真人误拒、误放、嗓音偏移和换人场景已完成校准。
