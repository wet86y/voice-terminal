# 桌面现场验收

本清单用于记录正式程序在实际设备上的验收。自动化回归、隔离模拟目录及正式包摘要校验各自证明有限边界，不能替代麦克风、扬声器、托盘或干净系统现场检查。当前正式构建状态见[交付记录](../releases/current-release.md)，自动化入口见[测试、启动与现场验收入口](operations-and-quality.md)。

## 已有验证边界

已记录的正式包在本机通过原生固定文件校验，程序与普通安装器使用同一统一程序包；旧工作区升级通过多组隔离合成数据场景。该结果不证明裸机依赖下载、真实用户旧环境升级或完整语音推理已在其他设备通过。

## 现场检查清单

| 检查项及中文说明 | 操作 | 合格条件 | 当前状态 |
| --- | --- | --- | --- |
| 干净设备首次安装 | 在没有项目开发环境的 Windows（操作系统）设备上安装正式包，分别检查有显卡与无显卡场景 | 管理页可用，必需运行环境、模型与 DSH（代理执行宿主）可安装；普通退出不残留受管进程 | 待验 |
| 旧工作区升级 | 使用真实旧版本工作区覆盖安装并重试异常模型迁移 | 用户设置、历史、模型和组件登记按升级策略保留；模型完整性失败时不破坏原资料，修复后可继续迁移 | 待验 |
| 语音可靠性 | 用实际设备检查环境声、主人及其他人语音、短句、打断、停止和重置耗时 | 拦截与输出许可符合当前设置；会话重置完成且不会重复播报 | 待验；修复已进入正式包 |
| 默认扬声器切换 | 播放期间切换 Windows 默认输出设备，再以双设备试听 | 播放流跟随系统新默认设备，待播队列不丢失或重复 | 待验 |
| 托盘与窗口生命周期 | 关闭窗口、托盘恢复、重复启动、跨屏拖动及明确退出 | 关闭按设置隐藏；重复启动恢复单实例；退出回收受管进程；多屏位置正确 | 待验 |
| 真实供应商与语音修订 | 在真实模型供应商会话中验证 revision（尾巴修订）、cancel（取消并替换）与播放结算 | 仅在适用边界执行；实际播放和聊天展示一致，无重复执行动作 | 待验 |
| 截屏消息生命周期 | 在真实桌面捕获全屏与局部图，检查关闭开关、恢复、重连及会话重置 | 图片状态、历史位置、附件恢复与当前会话边界一致；不重复发送不同事件 | 按实际设备与模型能力安排 |

## 记录格式

每次现场验收应记录构建编号、程序版本、Windows 版本、显卡与音频设备、测试场景、结果、未完成项及复测条件。表格字段含义如下：

| 字段 | 中文说明 |
| --- | --- |
| `build` | 正式程序构建编号 |
| `environment` | 操作系统、设备和运行环境摘要 |
| `scenario` | 检查场景及输入边界 |
| `result` | 通过、失败、未执行或受环境阻断 |
| `evidence` | 可复核的日志、截图或结果摘要；不得包含密钥及敏感用户内容 |
| `follow_up` | 后续动作与复测条件 |
