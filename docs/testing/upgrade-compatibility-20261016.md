## 风险与处理

此前审阅的P3（低优先级）风险是：外部替换保留模型内容时，新旧大小相同且保留旧修改时间，Python（后端运行环境）清单刷新可能复用旧摘要。这不是基于程序版本号拒绝升级。原生安装器重新读取实际内容，不依赖该时间戳缓存；有效组件收据可以纠正过期总清单。

本轮确认另一条条件性阻断：声纹迁移遇到旧模型与总清单不一致、又缺少有效安装收据确认时，原先会中止整笔本体安装。现在把这类问题限制在声纹迁移内：

1. 新程序包及官方声纹种子仍执行完整校验，失败时不启用新本体。
2. 无法确认保留模型内容时，暂缓整笔声纹迁移；原模型、模型总清单、组件登记和声纹资料均保持原样，不重新签发失效模型的摘要。
3. 程序本体可以继续更新，`app/release.json`（本体清单）中的 `deferred_migrations`（暂缓迁移记录）保存原因及后续动作。
4. 完整性检查仍会拒绝模型的失效内容；通过新版组件管理修复模型后，再运行安装器可以继续完成声纹迁移。

旧运行环境、模型或DSH（代理执行宿主）尚未满足当前版本时，本体安装与语音服务启动分别判断：本体可以更新，组件管理仍会提示更新或修复。只有当前必需组件满足版本和完整性要求，语音服务才启动。
