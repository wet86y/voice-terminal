# SSH（安全远程连接）管理员账户识别修订（2026-11-18）

## 对照依据与现场原因

本轮以上一次本机及分发共用的 product-0aa767d1461b8071（构建编号）为起点。按上次成功程序包的完整源码输入清单逐项比较，只有 system_feature.rs（系统功能模块，包含回归测试）发生变化，没有新增或删除程序输入；此前工作区编号及页面进度修订继续保留。完整摘要记录在本机 cache/reports/ssh-account-source-delta.json（源输入差异报告）。用户版本说明共用 docs/releases/v1.0.0.md（版本更新日志）。

两端已使用上一构建，配对资料和服务端设备信任均已保存。SSH 公钥认证失败的直接原因是：账户实际属于管理员组，但 WindowsIdentity.Groups（访问令牌有效组集合）会过滤掉 UAC（用户账户控制）未提权令牌中的 deny-only（仅用于拒绝权限）组。原系统状态和公钥登记均据此误判为普通账户，把受限公钥写入用户目录；实际 SSH 管理员匹配规则读取 ProgramData（系统共用数据目录）中的管理员公钥文件，后者现场不存在。

Windows PowerShell 5.1（系统命令行环境）下已复现原判断为假、账户库管理员归属为真；用户目录中的公钥指纹与程序设备信任登记一致。原始只读报告保存在 cache/reports/pairing-ssh-admin-key-path-diagnosis.json（公钥路径诊断报告）。

## 修订与定向验证

系统状态和公钥登记共用 Test-ProjectAdministratorAccount（判断账户管理员归属）：只接受 Windows 身份声明中的 GroupSid（有效账户组）或 DenyOnlySid（仅拒绝账户组）且值为内置管理员 SID（安全标识符）的声明，其他主体或设备组声明不参与账户判断。这一结果只决定授权文件位置及既有管理员任务入口，不代表当前进程已提权；登记脚本继续核对账户、预期组身份、路径、ACL（访问控制）、工作区和设备标记。

- 系统功能 33 项、设备桥接 4 项通过，共 37 项；原有两项人工只读系统验收保持忽略。新增声明测试包含未提权管理员、普通账户及非账户组声明拒绝。

## 使用与验收范围

本次程序更新不擅自移动系统公钥或改写 SSH 配置。先前写错位置的受限公钥须通过更新后的正式配对流程重新登记：服务端获取新配对码，客户端再次配对，服务端完成可能出现的管理员授权。原设备私钥和信任记录继续使用原有格式，登记相同身份会更新本程序拥有的受限授权行。

本轮测试覆盖真实账户识别及隔离文件写入，不等同于真实系统授权写入、双机 SSH 认证及双向音频验收。现场连接应在重新登记公钥后继续验证。
