# 系统脚本执行与编码边界修复

日期：2026-11-22（香港时间）。源码起点为 a4de280。本次承接[桥接默认解释器修复](ssh-bridge-shell-20261122.md)后的系统代码审查，修复三类边界问题；仅完成源码、本机回归与编译检查，未覆盖正式程序、测试目录或远端授权。

## 问题与修复

公共 PowerShell（系统脚本）执行器原先超时只结束直接进程，随后无限等待管道读取线程。审查现场设定 1500 毫秒超时，派生一个持有管道的六秒子进程，实际 6442 毫秒才返回。本次改为在进程运行前加入受管作业；超时、超量输出及主脚本结束时回收后代，收尾再等待最多两秒，并取消阻塞中的同步读写。标准输出、错误输出各限制为 4 MiB（兆二进制字节），超量返回失败，不把截断内容作为成功回执。

受限桥接原先仍使用无绝对路径的 powershell.exe（解释器命令），在默认命令行为 cmd.exe（系统命令行）时，当前目录中的同名程序可能被优先执行。本次从系统目录接口取得 Windows PowerShell 5.1（系统脚本环境）绝对路径并核验签名；只读 HKLM\SOFTWARE\OpenSSH（系统 SSH 配置）的 DefaultShell（默认解释器），分别使用 cmd 或 PowerShell 的正确调用语法，拒绝尚未支持的自定义解释器及无法安全表达的路径，不改写系统设置。该配置位置与默认行为参照[微软 OpenSSH 服务配置说明](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh-server-configuration)。

固定只读设备终端原先直接将系统代码页输出按 UTF-8（统一字符编码）解码，中文系统网络信息出现乱码。本次在输出入队前按本机 OEM（传统控制台）代码页增量转换，保留跨读取块的未完成字符；滚动缓存和每次增量读取维持字符边界，拒绝字符中间的偏移。偏移继续表示输出字节位置，现为规范化后的 UTF-8 字节位置。终端也从系统接口定位命令目录，并在取消或退出时先回收作业再排空输出。

SSH（安全远程连接）诊断优先接受 UTF-8。旧远端未声明编码时按本机系统代码页回退并明确标注推断；跨语言机器的代码页可能不同，不能据此保证识别所有远端编码。该处理仅用于有界错误说明，不转换桥接媒体或文件字节。

## 输出容量依据

本轮确认保留 4 MiB（兆二进制字节）上限：它是一次脚本执行中 stdout（标准输出）和 stderr（标准错误）各自累计接收的原始字节限制，两份缓存合计最多 8 MiB，另有解码开销；与脚本运行时长、独立音频和文件传输的大小无关。超过上限会停止本轮任务并明确报错，不返回截断的成功数据，也不自动重放可能已经产生副作用的操作。

已核对的正式调用为私有物理网络地址查询、解释器能力验证、SSH（安全远程连接）及防火墙状态摘要、系统维护与受限公钥登记；摘要限制候选规则数量，维护脚本抑制常规进度输出。从现有输出结构判断，该默认值具有较大余量；尚未统计所有现场的输出峰值，不把上述判断当作实测最大值。未来完整日志导出或大量枚举应使用流式文件输出或独立操作预算，不扩大所有调用的默认上限。容量策略见[进程管理说明](../architecture/process-management.md#系统脚本与终端输出边界)。

合计 63 项通过，2 项原有人工系统验收跳过。正式桌面程序启用 custom-protocol（正式资源协议）、native-audio（原生音频）及 ssh-device（设备连接）特性后的编译检查通过，原有未使用代码等警告保留。

源码只增加对现有 Windows（操作系统）接口的编译特性，不新增下载依赖、设置字段或持久化格式。测试复用固定原生构建缓存和现有解释器，隔离夹具在成功后回收；原始日志保存在 `.local/cache/reports/system-shell-fixes`（受管本机报告目录），审查时的原始复现保存在 `.local/cache/reports/system-shell-audit`（受管审查目录）。

## 生效与待验边界

本轮没有安装或发布程序，也未更改默认解释器、SSH 服务、公钥或用户配置。服务端部署修复后，仍需通过正式配对入口重新登记旧受限命令；以后更改默认解释器也需重新登记。真实双机管理、任务、媒体及文件通道仍待部署后验证，不以本机隔离回归替代现场结果。当前交付状态见[交付记录](../releases/current-release.md)，操作入口见[设备连接指南](../guides/device-connection.md#受限桥接命令解析失败)。
