# 局域网正式版本同步验证记录（2026-11-21）

本轮按正式产品版本号判断是否同步：同版本不同构建直接连接，异版需经项目弹窗确认，再由高版本向低版本传递维护分发器。未提升开发版本号，未执行本机覆盖、设备实际升级、分发交付或公开发行。

## 尚未完成的现场验收

需要两台已配对设备运行不同正式版本，且高版本设备持有与本机身份匹配的维护分发器，分别实测服务端向客户端提供分发器、客户端向服务端上传分发器、安装器接管、退出重启及新版本重连。还需现场验证传输中断、目标撤销信任和交接失败后的恢复。

目前两端若均为 1.0.0，将按设计视为同版，不会因构建编号不同触发更新。完全不支持稳定引导协议的旧程序需先经原正式更新路径升级一次。协议回环、组件回归及编译检查不等同于真实双机升级验收。
