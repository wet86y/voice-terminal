## 真实来源与完整摘要

四类文件通过新下载逻辑下载到独立临时目录，按现有清单核验大小和完整摘要；未替换现用组件。

| 文件 | 实际首选入口 | 已核验字节数 |
| --- | --- | ---: |
| Python（后端解释器）3.12.10 嵌入包 | 华为云镜像 | 11,133,606 |
| FastAPI（后端接口框架）0.115.6 安装包 | 清华镜像 | 94,843 |
| SmartTurn（语音结束判断）处理器版权重 | 固定提交的魔搭副本 | 8,679,182 |
| Sherpa-ONNX（唤醒词推理）模型归档 | 公共下载加速入口 | 32,885,699 |

此外，tiktoken（分词器）词表已按上游固定 SHA-256（文件摘要）验证，大小为 3,613,922 字节，随程序交付并保留许可证。屏蔽网络请求后，空缓存环境可以由随包词表完成缓存初始化并实际加载分词器；损坏缓存可以从随包文件恢复。随包词表缺失或损坏时，后台预热失败并保留既有字符估算，不触发原站下载。

前期来源审计还逐个确认 105 个 PyPI（Python 包索引）依赖与 4 个 PyTorch（张量框架）安装包在对应镜像存在且返回大小匹配；四个原外部模型资源的魔搭副本元数据摘要及大小与现有清单一致。这些检查不等同于已完整下载全部大型文件。

## 包装与资源身份

使用真实程序收集函数在独立临时目录组装程序内容，确认统一配置、原生调用的脚本辅助模块、后端模块、词表及许可证均进入程序包。打包目录中的 JavaScript（脚本语言）辅助模块可正常导入并读取随包配置。前端正式资源构建通过。

比较 Git（版本控制）差异，基础运行依赖锁、可选显卡依赖锁、模型资源清单及代理宿主规范锁均未改动。实际下载注册表单独作为诊断字段记录，保留原兼容判断和资源身份。

- 本专项源码验证阶段没有生成或发布新的完整发行包，也没有覆盖现用程序。随后已将改造编入 0.9.1，实际构建、本机升级及发行资产验证见[0.9.1 交付验证](release-0.9.1-20261018.md)。
- 未完成关闭 VPN（虚拟专用网络）的新设备全量安装，也未重跑所有大型模型、显卡依赖及真实代理宿主的完整联网安装。
- 更新清单仍由官方直接获取，公共加速只用于已有可信摘要的安装器附件；WebView2（微软网页运行引擎）保留官方安装入口。
- 公共下载加速入口未确认境内托管；不同地区和运营商的下载性能需要实机验证。第三方新增插件和生命周期脚本仍需随依赖升级复查。
