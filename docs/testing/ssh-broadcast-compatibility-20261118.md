# SSH（安全外壳连接）广播与配对兼容性修订记录

本轮基于上次实际本机安装 product-1b3e7f870674a156（1.0.0）检查。源码基线仍为 b2dcb71，加本会话尚未提交的修订；此前 DSH（代理执行宿主）、空控制台及提示条修复继续保留。本轮不修改设备配置格式、不下载组件、不修改用户原有 SSH 或防火墙规则。

## 已确认原因与修订

- 本机只读检查确认：Windows 把 192.168.253.0/24 返回为 192.168.253.0/255.255.255.0。原代码逐字比较子网，将等价范围判为失败。现将 IPv4（第四版网际协议）掩码及 IPv6（第六版网际协议）前缀统一为规范网络地址，再要求精确相等；拒绝 Any（任意来源）、LocalSubnet（通用本地子网）、更宽范围、不连续掩码、额外端口、错误方向、动作及网络配置文件。
- 原失败分支在管理员任务结束后再次发起清理授权。现将新入口回收放在同一管理员脚本，保留原先已启用的程序规则；取消或失败后不循环弹出清理授权。
- 原广播仅维护两个 TCP（传输控制协议）规则。现同轮管理 SSH 端口、18766 配对端口及 mDNS（多播设备发现）使用的 UDP（数据报协议）5353，绑定实际桌面程序或官方 SSH 程序、当前活动私有或域物理子网，不自动更改网络类别。
- Windows PowerShell 5.1（系统命令行运行环境）的公钥登记实际存在账户匹配表达式不合法、静态 HashData（摘要计算）及字符串重载不可用、空备份路径绑定导致文件替换失败。现使用该系统运行库提供的调用；状态输出显式采用 UTF-8（统一字符编码），同时读取标准和错误管道，避免诊断输出阻塞。
- 原设备操作由页面私有状态表示。现由原生宿主持有任务、目标、阶段、错误和递增快照；前端窗口共享正在进行的准备与保存，页面重建后继续读取，拒绝重复提交及迟到回执。初始慢速 SSH 读取独立于配置加载，不再阻塞运行模式。
- 配对客户端原先只等待 15 秒，可能早于服务端管理员确认而失败。现仅在已认证、等待最终公钥登记结果的阶段给予五分钟有界等待；其余帧仍为 15 秒。公钥登记在阻塞工作线程执行，服务端显示对应任务进度。信任保存失败时，受限桥接继续依赖独立设备信任门禁，不在错误清理中再次请求授权；相同身份可再次配对并更新原受管行。
- 公告同步、配对窗口和停止入口进行串行交接，耗时查询完成后重新核对角色、宿主代次与任务。界面保存及同实例启动参数复用同一路径；设备授权与工作区、更新、完整性维护在同一准入锁下互斥。
