## 事件与下一步

| 事件 | 自动处理 | 最终交给用户的操作 |
| --- | --- | --- |
| 下载、连接或传输错误 | 最多三轮，复用已校验缓存及可续传进度 | 检查网络后重试，不进入完整性校验 |
| 文件占用 | 短暂等待并重试，保留现用组件与事务 | 解除占用后重试；启动恢复受阻时处理后重新打开程序 |
| 空间不足、权限不足 | 停止无效重试，保留原内容与缓存 | 释放空间或恢复权限后继续，不据此判定内容损坏 |
| 已安装内容或候选加载异常 | 核验本机材料并局部重建受影响组件；运行依赖只重建可确认归属的包 | 局部恢复仍失败时引导已有全面完整性校验 |
| 原件、备份或登记的一致性无法保证 | 保留证据，停止不安全修改 | 引导全面完整性校验，由校验程序确定修复对象和程度 |
| 未分类操作错误 | 有限重试，保留具体原因 | 继续重试或查阅错误，不据此推断损坏 |
| 任务意外中断 | 启动时先恢复事务；未结算任务持久化为可重试 | 从组件页继续，原有缓存保持可复用 |

完整性校验始终包含程序和全部组件，没有按失败组件缩小扫描范围的新入口。只读扫描取消保留先前交接、兼容状态和事务证据。扫描中的文件占用或权限错误是操作阻塞，不登记为内容损坏、不清除组件。
