# CAM++ 原生声纹与流式准入更新验收

本记录描述初次功能交付。随后用户确认旧档案可删除，正式分发升级会卸载旧模型并删除已确认的旧档案，当前升级边界见[CAM++分发升级](../releases/campplus-distribution-upgrade-20261012.md)。下文旧档案摘要保留的结果属于初次验收历史记录。

交付日期：2026年10月12日。正式构建：`product-10f037a94ba4e273`（本地程序构建编号）。入口：`.local/VoiceTerminal.exe`。本轮功能验证完成，真实声学参数尚未校准。

官方模型为 `iic/speech_campplus_sv_zh-cn_16k-common`（中文通用声纹模型），固定 `v1.0.0`（权重版本），通过 FunASR/PyTorch（原生模型加载与张量推理框架）读取 `campplus_cn_common.bin`（本地权重文件）。引擎验证官方内容摘要、严格匹配937项参数，并在预热成功后报告就绪；计算输出为192维归一化向量。运行时不需要联网或CAM++的ONNX（模型交换格式）文件。新安装默认CPU（中央处理器）两线程，可选CUDA（显卡计算）并回退。

唯一400毫秒心跳提前100毫秒启动声纹计算。45毫秒有效输入即可开始，音频上下文增长至可调上限。设置版本、激活会话编号、输入代次和样本范围约束结果；重复音频不增加证据。超时沿用此前有效身份，迟到且仍有效的结果在后续心跳消费。持续低分只影响后续未放行增量，句尾与SenseVoice（精修模型）不重新否决已放行正文。

待确认正文及声纹证据暂存在有界内存账本。同轮补入和同一激活会话内跨轮距离恢复使用原始顺序、修订去重和批量事件；已确认非主人正文不自动恢复。取消、停止、精修和上下文创建的文本回退也使用获准正文，避免原始转写绕过筛选。原始转写可以作为界面诊断显示，但不能进入模型上下文。

人工开始或KWS（唤醒词检测）激活授予初始无条件放行并采集临时声纹。成功后固定会话质心，跨话语保留，直到停止、重置、关闭或真正进入静默。重复开始、恢复连接和模型播报不续期或重新授权。采集排除无效、无新增语音、明显异人和播放期间未通过回声保护的样本。失败到期恢复永久身份判断；此前放行正文保留。评分为永久分数与会话分数的可调加权组合。

设置保存格式为11版；后端整体校验非法组合。判断参数从下一心跳生效，采集参数从下一激活生效；调整权重不重建已固定的质心。既有用户的模式、主人阈值和连续放宽偏好保留。

测速复现：使用本地解释器运行 `scripts/validate-campplus-worker.py --stress-asr`（声纹往返与识别并发测速脚本）。结果和日志保存在 `.local/cache/campplus-validation`（本地验收缓存目录）。桌面原生启动门禁可用 `check-local-readiness`（原生只读验收示例）复核，不输出接口密钥正文。

本地运行核对：模型路径指向 `.local/models/speaker/campplus-zh-cn-common/campplus_cn_common.bin`，实际运行引擎为FunASR/PyTorch，现有用户的CUDA设备选择保留。45毫秒输入及特征指纹均为192维。旧WeSpeaker（旧声纹模型）的5个注册文件摘要保持一致，新档案独立存储在 `.local/data/speaker/campplus-zh-cn-common`；没有转换、删除或用于新模型回退评分。没有有效新档案时运行于观察状态，并提示需要重新注册。

真实语音验收仍需要用户重新录制三段永久主人声纹，之后用主人、异人、嗓音偏移和同句换人音频测量误拒与误放，再调整上述参数。当前本机保留旧主人阈值0.70及连续放宽0.10；这属于保存偏好，并非CAM++真实语音已校准参数。45毫秒可计算不等于45毫秒能可靠确认身份。
