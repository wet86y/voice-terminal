# SSH（安全远程连接）默认解释器桥接修复与本机验证

日期：2026-11-22（香港时间）。本次仅完成源码修复、本机验证与文档归档，未覆盖正式程序、测试目录或远端服务端，未修改实际系统授权。源码起点为 c293848；用户提供的测试程序为 v1.1.0、product-24f28e43783b9ebe。

## 故障与根因

连接失败提示“SSH（安全远程连接）受限桥接未就绪”，后附 PowerShell（命令行解释器）解析错误，其中包含 ssh-device-bridge（受限桥接入口）及“-- 运算符”相关文字，部分中文显示乱码。

原受限授权命令直接以带引号的桌面程序路径开头。该写法用于 cmd.exe（默认命令行）时可以启动程序，交给 PowerShell 时路径会成为字符串表达式，后续参数触发 UnexpectedToken（意外标记）和 OperatorRequiresVariableOrProperty（运算符要求变量或属性）两类错误。使用原命令形式在本机解析器中复现了这两类错误。此时桥接程序尚未启动，不能仅据此将故障归为设备信任、组件或防火墙问题。

## 源码修订

[受限公钥登记实现](../../apps/desktop/common/src/system_feature.rs)使用固定 powershell.exe（Windows PowerShell 启动命令）及 EncodedCommand（编码脚本参数），外层命令仅含 ASCII（基本字符集）内容。程序路径作为编码数据解码后交给 ProcessStartInfo（原生进程启动配置），工作区、账户、设备与桥接协议继续使用已经校验的固定参数，不拼接客户端原始远程命令。

启动包装通过原生进程直接继承标准输入、输出和错误句柄，不将媒体或文件内容送入文本管道；等待进程结束并传回退出状态。包装自身的启动异常使用 UTF-8（统一字符编码）写入独立错误通道，标准输出保留给桥接协议。

原授权行的来源子网、restrict（受限会话选项）、公钥和设备标记继续沿原入口登记；桥接仍核对工作区身份、账户、正式程序摘要、设备信任与原始通道标记。未改变系统默认解释器、SSH（安全外壳协议）配置或授权范围。兼容契约见[分布式设备运行架构](../architecture/distributed-device-runtime.md)。
