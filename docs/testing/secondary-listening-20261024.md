# 通用二等信箱与持续倾听验证记录

日期：2026-10-24（香港时区）。本记录对应源码实现，不代表已本机更新或完成真实语音现场验收。

## 实现与兼容范围

- 会话账本持有唯一通用二等存储，来源与类型开放；后台进度、声学观察和倾听标记使用统一版本消费路径。各生产者保留业务去重、合并与作用域校验。
- 模型从 `runtime.secondary_items`（本次冻结的二等条目）读取来源、类型和数据，不再从旧后台进度与声学字段重复读取。冻结及审计失败不消费，重试保留原快照。
- `continue_listening`（继续倾听）仅接受业务参数 `count`（新增注入次数），严格为整数1、2或3。未注入余额最多4，另有最多一条已注入标记；首次立即注入，后续消费清空后补入并扣数。
- `runtime.listening_request`（冻结的持续倾听状态）提供 `remaining`（尚未注入次数）与 `pending`（是否已注入未消费）。停止、结束与最终静默清理计划，旧请求不得借恢复后的新作用域重建计划。
- 混合评估因部分作用域失效而作废时，归还其他仍有效的冻结条目，不覆盖新版本，也不重复扣减注入次数。请求结算及会话结束清理请求级快照，避免长会话积累。
- 工具请求与发声独立；允许根据语境等待或自然衔接，不规定固定追问话术。保留四秒检查点、普通请求优先、单请求执行、活动播报权限和最终静默期限，不创建持久任务或新定时器。
