# 下载、更新与组件生命周期验证（2026-10-19）

本次修改由主会话完成。辅助代理只进行只读调查和回归验证。测试使用自动创建的临时工作区、本地回环服务和独立测试数据，未在用户现用工作区执行全量资源替换或在线更新安装。

## 行为与边界

- 管理页的应用更新检查、下载和取消具备本地页面权限，不依赖组件就绪或业务服务启动。更新下载最多三轮；等待交接期间可取消，实际安装器交接阶段关闭取消入口。
- “组件分类”标题右侧提供“一键下载”“资源导入”。一键任务由原生资源管理器持有，先处理完整 CPU（中央处理器）环境，再并行处理七个必需模型及 DSH（执行宿主）；本地语音模型、audio.cpp（原生语音框架）和显卡依赖不在其中。在线接口配置仍由用户完成。
- 下载和摘要校验分别计数，每个任务只显示一条当前阶段进度。文件下载后立即校验；仍有传输时优先展示整体下载阶段，安装和等待阶段使用不定进度。分类展开后不重复渲染任务汇总条。
- 资源处理最多三轮，恢复间隔为一秒、三秒。来源回退与资源恢复共用轮次；npm（包管理器）安装在原生任务内关闭嵌套网络重试，脚本包下载占用全局四通道中的一个。普通启动不自行下载。
- 同一缓存目标的互斥覆盖缓存核验、续传、提交及失效清理，等待可取消。本地文件占用不会误报成镜像来源失败。候选准备、组件事务、回滚和用户数据保留沿用受管路径边界。
- 模型下载只操作自身文件，不预检或安装 audio.cpp。播放目标按保存的后端和具体模型判断；目标不可用时提示补齐并保持选择，不自动回退。下载不改变启用状态，原先未启动的服务不会因安装而启动。
- 本地模型只有自身文件及框架满足当前版本时才进入音色设置可选列表；尚未加载不等于未就绪。切换失败恢复原模型；外部客户端借用模型不被误卸载；本程序发起加载但确认失败时仍清理该模型后回滚。
- Node.js（脚本运行环境）沿用系统安装，不新增私有下载。原生端及后端读取 `node_version_range`（兼容版本范围），当前为 `^22.19.0 || >=24.0.0`，来源于[目标 DSH 的上游声明](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/package.json#L7-L9)。22.20.1、24.9.1 等范围内版本均通过判断；23.x 不在上游支持范围内。只有完全未安装时，组件来源入口指向 Node.js 下载引导；已有但不兼容时保留实际诊断。

## 原有失败与实机范围

13 项旧协议断言已由辅助代理在未修改的原始版本隔离复现，涉及旧声学续接和参考提示请求字段。它们不是本次新引入的失败，本轮未改回已经停用的协议行为。过滤的五个函数为：

- `voxcpm2_ignores_legacy_emotions_and_formal_style_fields`（旧情绪字段断言）。
- `voxcpm2_formal_clone_uses_continuation_without_control`（旧声学续接断言）。
- `steps_hot_update_is_frozen_per_answer_and_new_answer_has_new_context`（旧续接上下文断言）。
- `voxcpm2_formal_clone_sends_reference_transcript`（旧参考提示请求字段断言）。
- `native_rate_multi_segment_streaming_keeps_transport_and_receipts`（旧多段请求协议断言）。

Windows 隔离工作区以正式管理页启动，缺少 CPU（中央处理器）环境及模型，业务服务未运行。通过实际界面点击“检查更新”，返回“已是最新版本”（0.9.2），未出现 ACL（访问控制权限）错误。正常宽度及 400 像素内容宽度下，已观察“组件分类”标题、按钮顺序、分类展开与语音模型卡片布局，未发现横向遮挡。窄窗口通过仅改变测试构建的初始尺寸验证，源码尺寸已恢复并重新构建。

启动前“语音播放目标”在保存的本地模型缺失时显示“当前选择未就绪，请补齐资源或选择其他目标”；实际下拉列表仅提供在线接口，不提供未就绪的本地模型，也未改写原选择或拉起业务服务。本轮隔离窗口验收后已退出。

补查修复了三个维护边界：应用更新与工作区操作原子预留互斥；维护取消或失败后保留原有服务恢复意图，原先未启动的服务不被启动；取消准入与安装器交接共用门闩，已接受取消的任务不能再进入安装交接。脚本包安装的原生任务轮次在清理工作区环境之后设置，避免嵌套重试重新失控。上述行为均已补充回归测试。

按本轮轻量实测范围，未重新下载全部大模型，未在真实麦克风会话中逐一加载所有模型。线上最新版本与当前版本均为 0.9.2，未执行真实新版本安装；交接配置、旧进程及锁释放使用独立进程和临时工作区实际验证。大文件下载与模型运行路径由回环下载夹具、原生事务与旧工作区升级测试、权限测试和后端替身回归覆盖，不能替代最终发行包的完整端到端验收。公共模块现有 11 项手动原生验收用例未全部执行，结果保留为忽略。

## 复验入口

前端使用 `npm test`（全量前端与受控开发入口）、`npm run typecheck`（类型检查）、`npm run frontend:build`（生产构建）及 `node --test tests/dsh-npm.test.mjs`（脚本包安装适配器）。

原生使用仓库本地 Rust（原生编程语言）工具链，指定 `--offline --locked`（离线使用已锁定依赖）、公共模块 `--features qualification`（开放回环隔离夹具），分别运行 `voice-desktop-common`（公共模块）和 `voice-terminal-desktop`（桌面模块）测试。

安装器另运行 `voice-terminal-installer`（安装器模块）测试；完整更新交接用例 `complete_update_config_and_parent_release_are_verified_in_isolation`（完整配置和旧进程释放隔离验收）需已有组装程序包，并显式指定 `--ignored`（运行手动验收项）。本轮该项已通过，不计入公共模块的 11 项忽略记录。

后端使用 `.local/runtimes/python/python.exe -B -X utf8 scripts/test-backend.py`（独立测试目录及正式解释器），仅对已确认的上述五个旧协议函数使用 `-k`（测试名称过滤）排除。DSH 分发测试文件为 `tests/test_dsh_npm_distribution.py`（宿主分发及系统脚本环境检测）。
