# 运行依赖增量更新修复验证（2026-10-28）

本轮针对新增小包导致整环境重复组装的问题，修改正式组件任务共用的运行环境更新入口。实际代码由主会话完成，辅助代理只读复审事务恢复及旧版本兼容边界。没有暂存、提交或改写版本历史。

## 变更与兼容边界

- 已有环境完整性校验后进入包级增删改计划。只解包变化包，只备份和换入变化文件；未变化依赖原位保留。首次安装、显式导入及确认损坏后的维修继续使用原入口。
- 第 1、2 版旧记录通过环境清单、安装文件记录与历史锁身份恢复逐包回执。最早没有整锁摘要和包名列表的离线记录，也支持从 `wheels`（原始预编译包回执）恢复实际内容身份。历史表覆盖仓库各版基础依赖锁和本轮当前锁，共 10 个完整摘要，包含 LF／CRLF（两种换行格式）身份。锁生成脚本在覆盖前自动登记旧内容身份。
- 历史兼容显卡组合使用实际安装版本和经完整校验的文件集合摘要，不冒充处理器包摘要。旧字段保持原含义，新字段驱动处理器隔离依赖的独立内容判断。
- 从新完整依赖闭包移除的受管包由后台组件任务卸载，只删其独占文件、元数据及派生字节码。共享命名空间文件、其它包和清单外文件保持保护。安装和卸载共用附加文件路径映射。
- 沿用正式资源任务的暂停服务、串行启用、恢复及附属登记事务。逐文件恢复验证旧内容摘要；缺少或损坏备份时保留记录并报错。新事务目标使旧程序在改动任何内容之前安全拒绝；无新目标的旧事务仍按原语义恢复。
- 加载失败、取消、缺少安装记录或历史身份均不自动退回全量安装。解释器版本改变必须显式处理，不伪装成普通依赖更新。

## 验证结果

本轮原生共用库 167 项通过、13 项显式集成项忽略；其中本轮运行环境真实增量集成项另外显式执行并通过。Python（后端语言）相关回归 36 项通过、13 项需要平台实机条件的集成项跳过。正式优化构建沿用已有 5 项未使用代码警告。

Python（后端语言）运行环境工作进程及进程宿主回归覆盖旧格式迁移、小包新增、同版本内容变更、卸载共享文件保护、无旧身份拒绝、历史显卡回执、处理器隔离依赖复用、缺少发行记录、附加文件映射和字节码清理。平台集成项的跳过保持明确标注。

原生共用库回归覆盖原本的组件、本体事务和旧安装兼容，以及新增逐文件恢复；逐次文件移动中断、重复恢复、原件与备份缺失／损坏、已提交后清理中断均有独立断言。

显式集成测试在仅有解释器标准库和微型依赖的夹具中执行真实下载计划、解包、增量换入、完整校验和加载。测试一次新增包、升级包和移除包，断言升级后旧独有模块退出、保留包修改时间不变；提交前取消保持原环境；故意声明错误版本使真实加载检查失败，确认恢复原环境清单、原文件和登记。该测试不下载大型依赖、不复制模型或第三方运行环境。
