# 远程媒体恢复与日志修订验证（2026-11-19）

## 范围

以 `6ca0f42`（版本基线）及本轮开始前已有的未提交修订为基础，继续保留其他会话改动。问题来源为本机根因审计及代码复核报告；没有更改用户设备配置，没有自动开启客户端合成，没有本机覆盖或远端安装。

## 行为与兼容

- 时钟映射仍以新鲜可信样本为依据。初始五轮中个别数值测量失败不再关闭整个媒体流；没有任何可信样本时，不提交交互租约。负往返容忍样本带实际误差，不再被当作零误差最优样本。
- 新端通过初始请求已有的 `fields`（中文字段说明）声明 `runtime_controls`（运行期控制扩展），客户端明确响应后才启用续测和输入重建。旧请求和旧端响应保持可解析；旧端未确认扩展时不发送新控制消息。双方更新后才能取得完整长时恢复能力。
- 运行期约每 10 秒续测，单样本 3 秒超时后约 1 秒再次尝试；过期映射不无限延长。已超时或重复测量回执不影响新样本。映射调整造成的采集时间倒退会保守修正，并增加相应误差说明。
- 监听停止关闭当前输入，重新开始创建新编号；媒体连接、固定目标的下行播放和授权生命周期独立。原输入的少量在途帧只在设备、核心和代次一致时丢弃，不能进入新一轮识别。异常流或已销毁媒体输入不可重启。
- 同租约的新旧媒体处理器以当前采集对象区分所有权。旧处理器不能借本机恢复收尾关闭新流；当前流真正结束时仍按现有租约流程回到本机。旧播放键保留原目标和不确定结果，不改投、不自动重播。
- 媒体就绪与监听成功分别反馈。监听暂未恢复时连接保留、意图登记、原因可查；用户停止可撤销恢复意图。
- 远程开始、停止均经既有已认证管理入口，服务端检查本设备当前媒体目标，防止媒体失效后误启动本机或其他设备。成功、延期与失败有不同结果；回执含糊不自动重发。
- 实时连接握手默认 10 秒超时，错误后进入可恢复的离线状态；旧连接关闭事件不影响新连接的图像通道。瞬时管理探测失败允许保留现有转发器最多 6 秒，管理写入仍关闭；明确拒绝或主动断开不采用宽限。
- 宿主从实际状态接口保存分能力列表。语音接口仍存活时，局部模型故障或加载不再把接口组件标为退出/失败；核心能力门禁仍按真实状态关闭。单能力恢复优先，旧核心缺少能力列表时先复用进程重新初始化；进程真正退出时才整体恢复。持恢复锁时发现进程退出，会排队重建，避免递归等待同一把锁。

## 日志

| 位置 | 内容及预算 |
| --- | --- |
| 服务端既有语音日志 | 媒体打开、就绪、正常及异常关闭；失败时钟样本的四个时间值；输入选择、启停及新编号；交互准备、完成、放弃与本机恢复；远端监听命令结果 |
| 服务端宿主日志 | 能力健康发生变化时记录一次；组件恢复请求来源、局部恢复选择及旧进程退出结果 |
| 客户端 `cache/logs/client.log`（客户端运行日志） | 启动版本和构建、连接尝试/成功/失败、媒体建立/就绪/结束、输入重建、合成请求与关键回执、设置新旧值及回滚；单行最多 4 KiB（千二进制字节），每文件 4 MiB（兆二进制字节），共三份滚动文件 |
| 日志导出 | 沿用既有日志归档器自动收录客户端日志及滚动文件；新增回归验证非空归档 |

设备关键事件携带 `device_id`（设备编号）、`core_session_id`（核心运行编号）、三个代次、`stream_id`（媒体连接编号）以及适用的 `capture_stream_id`（输入编号）。字段随记录提供中文说明。没有逐帧日志，不记录供应商凭据、合成正文或完整协议正文；写客户端日志失败不终止业务。

健康探测的识别连接边界降为调试级别，真实业务客户端的连接事件保留。声纹诊断仍保留完整关联信息、实际枚举中文说明和原有内容日志，只移除每条记录中未用到的整份静态枚举词典；没有删掉实际事件或文字证据。
