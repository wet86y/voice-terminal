# 悬浮窗主语音与后台链路实机测试

2026-11-23 在本机工作区通过正式根入口进入代理调试模式，使用项目调试接口驱动正式主窗口、悬浮球和图文窗口。图文及语音视觉状态采用正式原生命令投递可控内容，真实语音会话采用现用麦克风和配置。鼠标关注、窗口关闭与拖动补充使用电脑控制工具。

## 发现与修复

- 正式图文窗口报告已显示，实际卡片不可见，并持续重复展示回执。共用事件监听使用 Any（全局目标），图文窗口也接收了发给悬浮球的简化布局，正文在空值和有效请求之间反复切换。事件订阅现使用原生身份中的当前网页标签，代理调试调用器同步传递该身份。修复后实际卡片可见，观察期间仅有一次展示回执。
- 拒绝超过 500 字符的图文时，正式窗口线程停止响应。拒绝分支持有状态互斥锁，发送展示回执时再次获取同一把锁。现先释放锁再发送回执。修复后连续拒绝超长、超高、重复图片和加载失败内容，窗口均继续响应，既有卡片保持可见。

第一次卡死后正常退出请求未能释放窗口线程，核对程序路径及测试启动参数后终止了本轮创建的测试进程树，再通过正式本机更新入口换入修复构建。相关失败记录保留在受管报告目录。
