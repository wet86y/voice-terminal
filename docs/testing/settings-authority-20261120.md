# 服务端设置权威修订验证（2026-11-20）

本轮仅修订源码、文档并验证，没有构建、覆盖安装或更新两端现用程序。设置提交与消息契约见[分布式设备运行架构](../architecture/distributed-device-runtime.md#设置提交与服务端依据2026-11-20源码状态)。

## 修订范围

客户端通过既有固定管理操作提交设置请求，由服务端校验、持久化和应用。同项请求在服务端串行结算，回执附带 `settings_snapshot`（服务端最终完整设置快照）；不引入双端协商。单条指令请求只携带目标与操作，服务端基于当前列表处理。原整表请求保留显式替换语义。

保存失败恢复内存，防止失败修改混入后续写入；模型加载成功及失败恢复只更新本次实际变更字段，避免覆盖同期门禁和静默时段设置。设置实例与修订仅用于运行期同步，不改变第 20 版持久设置格式。

页面依据服务端修订补读，并覆盖进入设置、连接恢复及重新可见场景。旧修订、已退役实例和旧连接回执不回写当前页面。未提交输入仍保留；开关和保存结果以服务端结论为准。通知异常不将成功保存误报为失败。

人格资料的新会话生效规则、指令后续请求生效规则、授权边界及模型切换约定保持原意。

## 验证结果

- 前端类型检查通过；全量 43 个测试文件、556 项通过。
- 最终后端相关回归 90 项通过，涵盖设置存储、失败恢复、并发结算、运行配置、正式接口及远程操作登记一致性。
- 后端全量首轮 2509 项通过、17 项跳过、1 项失败。失败项为语音识别协议的 50 毫秒超时断言；原样复跑该测试文件，12 项全部通过。未修改语音识别链路或其测试断言，不将首轮全量记为全部通过。
- 差异空白检查通过。

主要回归位于 `tests/test_settings_authority.py`（服务端设置权威回归）、`apps/frontend/src/product/ProductApp.test.ts`（页面同步及草稿回归）、产品接口及语音合成、热词页面测试。真实业务路由保持使用；模型加载等待和写盘失败通过隔离边界控制。
