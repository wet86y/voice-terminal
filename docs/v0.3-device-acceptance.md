# V0.3 真人设备验收准备

本文是后续用户执行的现场清单。这里的内存播放器、合成文本和回放报告不能替代耳机或扬声器验收。每次测试使用 `config/v0.3.yaml`，打开 WebUI 的 `AGENT EPISODE` 面板，同时保存脱敏的 `agent.trace`、`speech.completed`、`turn.completed` 和延迟字段。

## 执行前

1. 启动 ASR Worker、Analysis Worker 和 Voice Server，确认 `/health` 与 WebSocket readiness 为 READY。
2. 分别准备耳机和扬声器；扬声器测试记录房间噪声、距离和音量，耳机测试记录型号和佩戴方式。
3. 清空上一轮日志，保留服务版本、配置摘要、设备信息和环境编号；不要保存密钥、完整模型上下文或原始音频，除非另有脱敏和授权。
4. 每个场景先确认 `Episode/Step/context_version/user_speaking/current_action`，再根据“预期声音”和“预期 Trace”判定。

## 场景表

| 编号 | 条件与操作 | 预期声音 | 预期 Trace/记录 | 判定 |
| --- | --- | --- | --- | --- |
| D01 | 耳机；说三段“先别回答”，最后不再讲话 | 无 TTS | 一个 Episode、三条 Turn、多个 `WAIT`，无轮询 | 三段输入完整且无声 |
| D02 | 扬声器；同 D01，检查回声 | 无 TTS | `user_speaking` 不因回声误变为真人插话 | 无旧输出泄漏 |
| D03 | 耳机；说“先听我说完”，停顿后继续，最后要求回答 | 只在最后要求后发声 | 等待 Step 被保留，最后一次 `SPEAK_ACCEPTED` | 没有中途抢话 |
| D04 | 扬声器；播放前说“等一下” | 不应开始旧回答 | `SPEAK_BLOCKED` 或 stale，旧 PCM 为 0 | 无首音泄漏 |
| D05 | 耳机；播放中真人插话并持续至少确认窗口 | 已传达前缀后停止 | `turn.interrupted`、`speech.completed`，delivery 有 heard/uncertain/unheard | 只接受受保护插话 |
| D06 | 扬声器；播放中拍手/环境噪声 | 继续原回答 | 不产生真人 Turn，不清空当前输出 | 抗噪声 |
| D07 | 任意设备；讲话期间误调用 speak（可用 fake 场景） | 无声 | `SPEAK_BLOCKED reason=user_speaking`，同链不重试 | 阻止而不排队补播 |
| D08 | 任意设备；文件查询预读后改换意图 | 只回答新意图 | 旧 speculative 交换不进入新 `llm.context` | 旧结果不污染 |
| D09 | 任意设备；完成文件查询后改换意图，再重新询问同一文件 | 第二次可复用但只在重新选择后 | `TOOL_STARTED reused=true`，来源仍保留旧执行身份 | 缓存准入正确 |
| D10 | 任意设备；数字、路径、版本号精修 | 按实质变化重新决策 | `context_version` 只在实质修正递增 | 不误判展示变化 |
| D11 | 任意设备；中文逗号/句末符号精修 | 不重新发声 | 无新 Agent 请求 | 纯展示修正合并 |
| D12 | 耳机；连续五轮输入 | 每轮按 Agent 选择 | 主模型并发始终 1，Trace 不积压旧事件 | 无追赶式轮询 |
| D13 | 扬声器；停止讲话等待 5.5 秒 | 静音机会最多触发一次 | `SILENCE_TIMEOUT` 一次；再次等待不重复 | 重新讲话后才获得机会 |
| D14 | 任意设备；`session.stop` 在讲话中 | 立即停止采集和输出 | Turn 有稳定 Episode ID，`turn.completed` 一次 | 历史不丢归属 |
| D15 | 任意设备；停止后重新 `session.start` | 新 Episode 的输出独立 | 旧 Step/输出 Trace 可见但不覆盖当前状态 | 新旧隔离 |
| D16 | 任意设备；断开 ASR/Analysis 后恢复 | 恢复前不发声；恢复后可继续 | 状态 `ERROR/DEGRADED` 后重新 READY，情绪不可用时为 `UNAVAILABLE` | 不把缺失当判断 |
| D17 | 耳机；Bidi 播放开始期间停止 | 旧音频不恢复 | cancel 屏障完成，下一次 session 可复用或已关闭 | 无活动连接泄漏 |
| D18 | 扬声器；首 PCM 前插话 | 无首音或只保留可信前缀 | 输出状态为 interrupted/stale，delivery 精度如实 | 首 PCM 门控正确 |
| D19 | 任意设备；重连 WebSocket | 页面恢复当前输出摘要和有界历史 | 快照不重复追加 Trace，旧 progress 不复活 | 重连一致 |
| D20 | 任意设备；多轮持续使用至上下文限制 | 达到限制后保持静音 | `CONTEXT_LIMIT`、界面提示停止并重新开始 | 不偷偷总结/重试 |

## 记录字段

每条场景至少记录：`case_id`、日期时间、设备/驱动、耳机或扬声器、房间噪声、音量、配置摘要、Episode ID、每个 Turn ID、Step、context version、用户讲话状态、唤醒原因、模型请求数、Speak 接受/阻止/丢弃、工具执行/复用/丢弃、输出状态、delivery、输入结束到首 TTS/首 PCM/首播放延迟、最终判定和备注。
