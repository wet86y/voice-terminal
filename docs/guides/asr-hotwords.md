# 热词替换

在“设置 → 识别与修订”页面的“热词替换”区域中按热词、别名、排除词三列维护条目。总开关与流式修订开关分行呈现，两张卡片左右对齐；后者只控制主流式文本修订。热词表区域将条数、搜索、添加、导入、词条列表及分页集中显示，窄面板会自动调整词条与操作按钮布局；列表为空时按提示文字高度紧凑显示添加或批量导入提示，详细输入规则可从“填写说明”展开查看。

点击“导入词表”会打开完整词表 JSON（轻量级数据交换格式）编辑器，内容为当前已保存词表；可直接复制、粘贴并批量修订。保存会校验并立即写入，不处理词表文件。
中文目标词按音素匹配；英文名称可把常见中文读音写入别名，让读音相近的识别结果归一到同一个目标词。
页面支持按目标词或别名搜索、每页 20 条及数字分页；列表可视区域最多显示 5 条，受窗口高度限制时可更少，其余词条在列表内滚动查看。热词总数显示在热词表标题旁；“填写说明”与分页按钮在底部同行显示，页码保留首尾及当前页附近范围，中间未显示的页码用省略号表示。
JSON 编辑器保存完整词表并从下一轮发言生效，无需重启；页面上的其它设置草稿仍由“保存热词设置”提交。当前轮次的续段、定稿和精修沿用轮次开始时的词表。

配置字段说明：

| 字段 | 中文说明 | 含义 |
| --- | --- | --- |
| `enabled` | 热词总开关 | 关闭后保留词表，主流式和离线均不使用热词。 |
| `stream_enabled` | 流式热词开关 | 默认开启；只控制主流式的增量和最终后置纠正。 |
| `threshold` | 相似度门槛 | 取值 0.5～1，默认 0.85；调高会要求读音更接近，降低误替换机会，也可能漏掉读音差异较大的识别错误。 |
| `entries` | 目标词列表 | 最多 5000 条，每条目标词必须唯一。 |
| `word` | 目标词 | 最终希望保留的正确写法。 |
| `aliases` | 别名或读音 | 可填写常见拼写、中文读音或识别错词，都映射到目标词；每个目标词最多 8 个。 |
| `blacklist` | 邻近排除词 | 目标词附近出现这些词时抑制替换；每个目标词最多 8 个。 |

JSON 编辑器只接受词条数组。`word`（目标词）必填；`aliases`（别名）与 `blacklist`（邻近排除词）可省略，省略时按空数组保存。示例如下：

```json
[
  { "word": "Claude", "aliases": ["克劳德", "克劳得"] },
  { "word": "傅平" },
  { "word": "open source", "aliases": ["开源"], "blacklist": ["精准", "脱贫"] }
]
```

省略 `aliases`（别名）和 `blacklist`（邻近排除词）时，词条会分别补成空数组；显式提供时须为字符串数组。未知字段、无效 JSON 和重复目标词会被拒绝。空词表使用 `[]`；编辑器外的示例不会自动写入词表。

最多 5000 个目标词；每个目标词最多 8 个别名和 8 个邻近排除词，每个值最多 96 个字符；词表最多 1 MiB（二进制兆字节）。词条值不能包含 `|`、`~`、换行或空字符，也不能以 `#`（井号）开头。相似度门槛默认 0.85，可以在高级设置中调整。
词表持久化到当前工作区的 `product-settings.json`（产品设置文件）中的
`hotwords`（热词配置）字段，与其他产品设置一起迁移。

## 输入处理

Paraformer（流式识别）→ 实时标点 → 原始短句编号 → 热词纠正副本 → 原心跳调度。
SentenceStore（句子存储器）保留原文、编号；LLM（大语言模型）与用户历史使用纠正稿。
最终稿的 `raw_text`（原文）和 `hotwords`（替换与耗时明细）存入历史详情，
ContextualParaformer（热词增强离线识别）单独保存为 `raw_refined_text`（精修原文），互不覆盖；界面正文始终使用主流式稿。
声纹准入恢复同样纠正，只处理已获准文本。

离线精修仅将目标词注入模型，使用逐行词表保留英文短语边界；别名、排除词和相似度阈值只用于流式后置纠正。离线输出不再执行后置热词处理。每次调用显式设置或清空热词，音色参考音频的两条识别路线始终禁止热词，也不剥离唤醒词。

不跨逗号、句号、问号、感叹号、分号或换行进行热词匹配。长度强制分句时，
避开已经完整出现的目标词和别名；未知近音错词恰好跨强制切点时，最终稿补纠正。
最终句子副本与最终纠正文本对齐，保留原始句子编号及原文；识别回退改变已封口
前缀时，保留原句记录，通过独立最终稿提供纠正证据，不伪造编号。

## 时效与生命周期

保存时在后台校验、构建和预热两个匹配器，写盘成功后切换词表。
同一轮发言的续段、定稿及精修固定使用该轮开始时的词表，保留最近 64 轮。
流式短句与整句使用不同执行通道，默认等待预算分别为 50 和 100 毫秒。
超时、繁忙或异常保留原文，迟到结果不覆盖已提交文本；超时线程仍执行时，
不向同通道堆积任务。流式失败或强制分句的原稿可在最终稿通道补纠正。
会话重置与组件重初始化隔离旧执行通道，进程退出释放线程执行器。

预算仅覆盖新增热词处理，并不保证语音识别、标点、通信和心跳消费的总耗时
低于 400 毫秒。新增测试不替代真实麦克风、模型并发及真实业务词表的验收。
