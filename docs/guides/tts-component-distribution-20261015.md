# TTS（语音合成）组件与分发下载

“语音合成”分类下固定显示一个 **TTS（语音合成）** 条目和 MiniMax 在线 API（语音合成接口）。TTS 条目即使尚未配置或正在启动，也能展开详情。分类下载清单可选择下载 VoxCPM2（第二代本地语音模型）、VoxCPM1（第一代本地语音模型），或同时选择两者；确认后对应下载任务并行启动。下载完成后，在“语音与音色”页选择播放后端，不在下载过程中自动切换正在使用的模型。密钥配置和在线套餐用量位于 MiniMax 在线 API 组件详情，界面结构见[组件设置与分类下载](component-settings.md)。

## 启动规则

语音合成组件满足以下任一条件即可通过启动检查：

- 在线 MiniMax API（语音接口）密钥已经配置。
- 共用的 audio.cpp（原生音频推理框架）运行程序与任意一款本地模型完整可用。

其他识别、唤醒、标点和代理组件仍按各自的必需资源规则检查。只安装一款本地语音模型不会被另一款缺失、损坏或待更新阻塞。当前选择仍可用时优先保留；其资源不可用时，启动流程选择已安装的另一款模型或已配置的在线接口。全部不可用时明确提示需要安装或配置，不再让客户端构造异常中断会话初始化。

新安装的本地运行程序和模型具有 `resource-install.json`（安装收据）。启动选路会核对已有收据的文件内容；此前迁入、没有收据的本地权重则按随包资源清单核对大小与完整摘要，避免相同大小的损坏文件被误当成可用候选。摘要读取在线程中进行，保持服务接口可响应；当前已选择并配置在线接口时直接保留在线后端，不为未使用的本地模型读取全部权重。此前迁入的本机模型和经验证的原生程序继续兼容。

两款权重均固定文件大小和 SHA-256（文件摘要），只下载所需文件，不拉取整个仓库。权重位于 `models/audiocpp/tts`（语音模型目录），共用原生程序位于 `models/audiocpp/runtime`（原生组件目录）。

程序本体另外携带 `voxcpm-patch.zip`（原生覆盖补丁，约 40.7 MiB，准确字节数与摘要由资源清单锁定）与默认参考音频。补丁不计入上述远端下载量；官方归档、随包补丁和最终 28 个运行文件分别校验。最终原生组件约 1.02 GiB（吉二进制字节），没有包含本地语音权重或用户音色库。

官方来源：[v0.9.1 发行页](https://github.com/0xShug0/audio.cpp/releases/tag/v0.9.1)、[固定附件与摘要](https://github.com/0xShug0/audio.cpp/releases/expanded_assets/v0.9.1)。模型来源：[锁定提交的模型仓库](https://huggingface.co/audio-cpp/audio.cpp-gguf/tree/1b5981b2b89a1af578ebba5c8cf34226810e1f55)。

## 官方包与随包补丁

随包原生补丁通过固定资源目录锁定版本和摘要，并在安装事务中逐文件核验；产品行为以公开的接口说明和资源清单为准。本机诊断和验证记录不作为发行内容。

安装流程为：下载两份固定官方归档，校验完整摘要，解压到任务暂存目录，覆盖随本体提供的服务程序及两份模型规格，再逐文件核验最终目录并签发安装收据，最后通过现有事务启用组件。客户机不编译源码、不下载开发工具。补丁包同时保存 `source.patch`（相对官方版本的源码差异），官方许可证随运行程序保留。

两款模型同时下载时，资源管理器协调共享原生程序的准备及复用，两款权重可并行下载。共享程序只准备一次，后续任务复用通过校验的安装；取消及传输失败保留下载缓存，重试仍绑定同一版本和摘要。覆盖发生在暂存目录，最终启用沿用已有备份、回滚与服务恢复流程。

维护者更新补丁时，先取得两份官方归档及包含固定修订的原生源码仓库，再运行：

```powershell
.local/runtimes/python/python.exe -B -X utf8 scripts/prepare-audiocpp-patch.py --source-repo '<原生源码仓库绝对路径>'
```

`--source-repo`（原生源码仓库）、`--runtime`（已验证的本机资源目录）、`--cache`（官方归档缓存）均为构建准备参数。脚本拒绝未知服务程序摘要及不匹配的官方归档，生成随包覆盖补丁并更新 `config/resources/catalog.json`（固定资源目录）。正式程序组装会收集此目录及补丁，无需另配本项目补丁下载站点。

## 参考音频与切换修复

现场日志中的参考音频读取失败有明确原因：音频文件存在，但音频读取接口没有导入 `Response`（二进制响应对象），返回了 500（服务内部错误）。现已修复；存在的素材返回音频，实际缺失的素材返回 404（未找到）。

默认参考音频及其准确转写随本体提供，用于全新安装初始化两个独立音色库。默认项已有索引但文件丢失时，可使用匹配的默认种子恢复原素材编号，保留已启用音色与历史音色版本；用户后来修改过默认转写或更换过录音时，不用种子覆盖，提示重新导入，即使新录音转写相同也保留这一保护。用户音色仍保存于用户数据目录。

模型切换队列在取得切换锁后重新确认当前后端，避免在线切换先完成后，排队的本地切换又在后台加载模型。保留既有播报结算屏障、失败回滚、播放器时钟和独立音色库规则。
