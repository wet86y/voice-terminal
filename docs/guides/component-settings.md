# 组件设置与分类下载

组件设置采用“用途分类 → 组件 → 组件详情”三级展开。设置页与启动前的组件管理器共用分类和详情内容；启动前不再提供独立的“模型管理”页面。旧版 `models`（模型管理）页面链接会转到组件设置。

## 分类

| 分类 | 包含组件 | 中文说明 |
| --- | --- | --- |
| 语音识别 | Paraformer、SenseVoiceSmall、SmartTurn、CTTransformerStreaming | 分别负责流式语音识别、语音理解、语音轮次判断和流式标点补全 |
| 语音合成 | VoxCPM1、VoxCPM2、MiniMax 在线 API | 两种本地语音模型与在线语音服务配置；播放后端和音色仍在“语音与音色”设置中选择 |
| 推理执行 | DeepSeek 在线 API、DSH | DeepSeek 负责在线推理；DSH（代理执行宿主）负责代理任务 |
| 拓展组件 | KWS、CAM++、FSMN-VAD、热词修订 | 分别负责关键词唤醒、声纹、语音活动检测和识别结果热词修订 |
| Voice Server | Voice Server | 独立卡片，负责本地 Python（后端解释器）和共享语音运行环境 |

点击分类标题展开组件；展开组件详情可查看运行状态、资源状态、运行位置及可用设置。组件状态和文件资源状态分别展示：进程异常不代表资源文件损坏，已安装资源也不代表对应运行进程当前可用。

## TTS 就绪规则

TTS（语音合成）组件以下任一条件成立即可通过组件校验：

- VoxCPM1（第一代本地语音模型）及共用 audio.cpp（原生音频推理程序）运行资源就绪。
- VoxCPM2（第二代本地语音模型）及共用 audio.cpp 运行资源就绪。
- MiniMax 在线 API（语音合成接口）密钥已配置。

两款本地模型可各自下载；共享运行程序只需就绪一次。MiniMax 是在线配置项，不是下载资源。组件设置负责安装资源和保存在线密钥；真正使用哪种语音后端以及所用音色仍由“语音与音色”页面管理。具体文件、来源及安装校验见 [TTS 组件分发](tts-component-distribution-20261015.md)。

## 分类下载

每张分类卡片上的下载或配置按钮会先打开确认清单。清单列出该分类的组件、资源状态、计划操作、预计下载内容及共享依赖，再由用户确认启动。已就绪资源会标记为跳过；在线 API、内置能力及没有独立文件的热词修订会标记为无需下载。Voice Server 卡片也使用该清单展示运行环境计划。

TTS 清单允许勾选 VoxCPM1、VoxCPM2 或两者；未选择的可选本地模型不会创建任务。若本地模型已就绪但共享运行程序缺失，清单会说明将补齐共享资源。确认后所选任务并行启动；资源管理器协调共享依赖、重复任务和资源启用，避免两款模型重复安装共同运行程序。每个组件仍有独立进度、错误和重试状态；失败的单项可以单独重试。

下载计划中的 `resource_id`（固定资源编号）、`model_bytes`（模型文件最大字节数）、`shared_resources`（共享资源清单）、`optional`（可选下载项）和 `forcePlan`（资源已存在但需补齐依赖时仍生成计划）均用于说明计划内容，不会取代后端对固定来源、版本和文件摘要的校验。

## 在线服务密钥与用量

DeepSeek 的密钥配置位于“推理执行 → DeepSeek 在线 API”详情；MiniMax 的密钥配置位于“语音合成 → MiniMax 在线 API”详情。可在启动前管理器配置密钥，无须先安装全部模型。密钥写入当前 Windows（操作系统）用户的系统凭据库；设置文件只保存凭据引用，前端只接收“已配置”状态。留空提交不会清除已有密钥。

服务端只读代理接口 `GET /api/v1/models/credentials/{provider}/usage`（查询固定在线服务账户用量）从本机凭据库读取密钥并请求服务商。`provider`（服务商编号）当前为 `deepseek`（DeepSeek）或 `minimax`（MiniMax）。接口响应中的 `provider`（服务商编号）和 `data`（账户统计数据）均不包含密钥；后端会过滤服务商响应中的敏感字段并遮蔽回显的密钥文本。

DeepSeek 详情展示官方接口返回的账户余额明细。MiniMax 详情展示 Token Plan（令牌套餐）余量；该查询只适用于相应订阅计划，不代表普通按量付费账户的账户余额。未配置密钥时不能查询；网络错误、账号类型不适用或服务商响应无法解析时显示可读错误，不影响组件就绪状态。前端用量响应类型字段如下：

| 字段 | 中文说明 |
| --- | --- |
| `provider` | 服务商编号：`deepseek` 或 `minimax` |
| `data` | 公开账户统计；DeepSeek 为余额明细，MiniMax 为 Token Plan 余量；不含密钥 |

## 旧页面入口

“模型管理”单独页面已移除。DeepSeek 和 MiniMax 的密钥编辑与用量查询均放在各自组件详情中，启动前管理器也使用同一位置。因此缺少密钥时，可以直接从组件设置补全；历史 `models` 页面链接重定向到组件设置。语音运行环境和模型资源操作仍由各分类卡片承担。
