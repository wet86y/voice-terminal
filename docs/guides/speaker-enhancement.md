# 可选声纹增强

声纹是 Voice Terminal（语音终端）的可选身份旁路。音频采集、AEC（回声消除）、VAD（语音活动检测）与 ASR（自动语音识别）持续运行；普通输入的声纹拦截采用“首段确认、整轮放行”。设置入口为“设置 → 识别与修订”。

## 声纹筛选与首段确认

设置页用“声纹筛选”开关直接启用或关闭普通输入筛选：开启对应 `filter`（筛选），关闭对应 `off`（关闭）。筛选须有有效的主人声纹档案及可用的工作进程；条件不满足时服务会暂缓拦截，普通输入保留全文。`observe`（仅观察）仅用于服务不可用时的保护性降级，不作为独立运行模式提供给用户。 “仅主人可打断”是独立开关，关闭声纹筛选时仍可单独使用。

| 模式 | 普通输入行为 |
| --- | --- |
| `off`（关闭） | 不按声纹拦截普通输入。 |
| `filter`（拦截） | 每轮约 1.2 秒起核对首段；未知时延长检查，开口最多 4 秒仍未知则拦截，确认主人后完整放行。 |

复用现有 400 毫秒心跳及声纹分析时隙，以本轮实际语音起点计算 1.2 秒，不按全局心跳数量截取。首次使用本轮开头 1.2 秒；无法判断时，随新增音频扩大从句首开始的窗口，最多覆盖 4 秒。同一音频末端及设置版本不重复推理，重叠窗口不重复累计有效人声。用户说完的短句使用已有音频完成末次检查，仍未知则拦截，不补静音凑足四秒。

首段推理异步执行，不阻塞采集或识别。身份等待硬上限从实际开口起算 4 秒，包含积累、排队及推理时间，不在四秒之后再追加一次请求超时；独立截止计时在没有新增音频或推理仍在途时也会执行拦截，迟到首段结果不能重新放行。超过 100 毫秒软预算、但尚未达到硬截止的有效结果仍可消费。校准期临时授权及跨轮连续资格都不绕过当前轮次的首段确认。

待判及拦截期间持续识别并缓存完整原文，暂缓向主界面及对话模型发布正文。确认主人后立即补齐缓存的句首，后续恢复正常更新；实时稿、最终稿、精修稿及状态快照共用准入边界，不以空文字更新代替拦截。同一可见正文的重复流式事件去重；空的声纹拦截记录保留诊断及顺序号，但不生成主界面的转写占位气泡。

| 首段及后续情况 | 本轮处理 |
| --- | --- |
| 首段分数达到本次正常或跨轮放宽阈值 | 补齐全部句首文字，进入轮内放宽阶段。 |
| 首段有效分数低于本次正常或跨轮放宽阈值 | 判为非主人，暂缓提交，持续保存音频及完整转写。 |
| 首段质量不足、服务异常、无有效分数或请求超时 | 保留原文继续等待新增音频；开口四秒或短句闭段仍未确认时，按非主人拦截分支处理。诊断保留身份未知及到期或闭段原因，不伪造非主人评分。 |
| 暂缓后连续 3 次有效新结果达到正常主人阈值 | 推翻初判，恢复本轮从开头开始的全文，并标注疑似外来声纹或首段误判。 |
| 放行后连续明确非主人结果达到配置次数 | 标注疑似异声，撤销后续跨轮资格；本轮全文继续放行。 |

恢复计数使用正常主人阈值；有效未达标结果清零计数，静音、重复音频及异常不充数。放行状态绑定逻辑轮次，同轮停顿续说继承，下一轮重新核对首段。已结束轮次不会凭下一轮的主人证据再次触发响应。

`owner_only_barge_in`（仅主人可打断）共享同一跨轮连续资格，保留独立候选判断与回声保护。关闭普通声纹模式时也可单独启用。原有校准期临时打断授权保留，日志单独写明依据；普通输入的整轮放行状态不能直接授权另一个打断候选，也不能绕过普通首段认证。

## 统一轮次边界与连续资格

轮次由 SmartTurn（智能断句）及硬静音、最长时长、关闭智能断句时的 VAD（语音活动检测）兜底共同界定。识别子流变化及 `generation`（输入代次）递增不单独分轮。软闭段等待定稿时若恢复续说，撤销候选边界并保留同轮准入；最终成立后才交接连续资格。最长时长硬边界保持现有强制分轮行为。

跨轮资格从最终成立轮次的实际语音终点起算，真实时间包括助手播报与静音，不从声纹推理完成或识别定稿时刻重新计时。新轮在实际开口时锁定是否具有资格；开口时有效，即使首段积累或推理过程中到期，该轮仍按已锁定的跨轮阈值认证。到期后的其他新轮不能继承。

正常主人轮次可更新资格起点；仅达到放宽阈值的轮次承接原资格，不能无限续期。无有效分数、超时不续期；连续非主人撤销后续资格，本轮全文保留。首段负判不额外增加连续计数，沿用现有后续心跳计数语义。未完成三次恢复的暂缓轮次，不能凭一次高分成为新的主人来源。

停止、重置、故障取消、关闭及退回关键词监听会清理对应资格。临时声纹评分基准按原激活范围保留，不因普通输入闭段重新校准。

## 评分与参数生效

设置页默认收起“高级”区域；展开后可调整四项滑块，步长均为 0.01。其余有效参数作为内部配置保留，不再展示高级参数表。

| 可见参数 | 保存范围 | 默认值 |
| --- | --- | --- |
| 主人确认阈值 | 0–1 | 0.60 |
| 会话内连续放宽余量 | 0–0.30 | 0.10 |
| 会话间连续放宽余量 | 0–0.20 | 0.10 |
| 临时声纹权重 | 0–0.80 | 0.60 |

保存时分别检查基准值减轮内余量、基准值减跨轮余量都不小于0。等于0可保存；负值显示中文错误，保留草稿与原设置，不自动夹紧或改写余量。两种余量不相加。恢复默认只更新这四项，保留模式、主人打断偏好及内部参数；四项保存只提交可见值，服务端合并已有内部设置。

- 组合分数 = 永久登记分数 × (1 − 实际会话权重) + 临时会话分数 × 实际会话权重。
- 临时声纹尚未建立时，实际会话权重为 0，日志中的会话分数为不可用；保存的权重数值继续保留。
- 只有一个 `confirm_threshold`（声纹放行基准值）：无连续资格的新轮首段使用基准值；有连续资格的新轮首段使用基准值减 `continuity_relaxation`（跨轮次放宽量）；本轮确认主人后使用基准值减 `intra_turn_relaxation`（轮次内放宽量）。两种放宽独立，不叠减，派生阈值最低为 0。初判翻转的三次恢复始终使用正常基准值。
- 放宽阈值实际用于本轮后续的 `observation_state`（当次身份观察状态）及连续主人计数；当前观察变为未知或非主人也不撤销整轮放行。
- 有效分数按当次阈值二分：达到为主人，低于为非主人，没有分数灰区或独立非主人阈值。后续低分累计连续异声次数；达到既有次数后标注并撤销后续资格，已放行全文保留。无有效分数不计入正反向计数。
- `non_owner_threshold`（旧独立非主人阈值）已淘汰：旧配置与旧客户端字段兼容忽略，不进入新保存值或运行判定。`identity_result`（当次有效身份结果）与累计身份状态分开写日志；独立打断仍保留已有的连续确认及回声保护。
- 现场测试展示永久登记评分；实时会话可能叠加临时声纹。界面及日志分别展示分数来源，不把二者混为同一结果。

| 参数 | 实际用途 | 生效时点 |
| --- | --- | --- |
| `confirm_threshold`（放行基准值） | 正常首段确认、正常主人证据及三次恢复 | 下次判断 |
| `intra_turn_relaxation`（轮次内放宽量） | 已确认主人后，本轮判断的放宽量 | 下次判断 |
| `continuity_relaxation`（跨轮次放宽量） | 新轮实际开口时资格有效，首段采用的放宽量 | 下次相应判断 |
| `non_owner_ticks`（异声连续次数） | 异声标注及后续连续资格撤销，不撤销本轮全文 | 下次判断 |
| `session_weight`（会话声纹权重） | 临时声纹可用时的实际评分混合 | 下次判断 |
| `context_max_ms`（滚动上下文上限） | 首段之后的心跳分析窗口 | 下次滚动分析 |
| `calibration_speech_ms`（校准有效人声量）、`calibration_max_ms`（校准最长时间）、`calibration_similarity`（校准一致性） | 采集及固定会话声纹 | 下次激活 |
| `enrollment_*`（登记质量参数） | 永久声纹登记 | 下次登记 |
| `pending_ttl_ms`（闭段记录期限）、`pending_max_turns`（闭段记录数上限） | 已关闭的诊断/待处理记录留存 | 下次记录管理 |
| `continuity_window_ms`（连续进入时限）、`continuity_max_ms`（连续最长时限） | 普通输入与主人打断共享的跨轮资格，分别限制进入及原证据链最长范围 | 下次实际语音开口 |
| `recovery_max_distance`（兼容片段恢复距离） | 旧片段恢复兼容路径 | 不用于新普通输入恢复 |

设置热更新时清空未完成的连续计数；主人阈值、两种放宽量、评分权重或连续时限改变时清除旧跨轮资格。旧设置版本的在途首段结果仅记录诊断，再按新版本重算；已放行轮次保持有效。旧设置缺少轮内量时，兼容读取此前实际使用的放宽量，不覆盖已有跨轮值。旧的控制器窗口、最小人声及等待参数不再作为另一套实时参数来源。

旧保存值读取继续经现有兼容合并入口，不在读取时重写文件。历史临时权重大于0.80时保留原值及内部参数，界面显示原数值及范围提示；显式保存四项前需调整到新范围。只切运行开关不携带权重草稿。旧派生负值保留此前0下限的读取行为，下一次编辑保存四项时执行非负校验。运行应用失败时恢复保存前的可信快照，历史范围不会阻止回滚。

## 原文、精修与上下文

原始转写、实际放行稿、热词替换稿及精修稿分别保存。获准轮次从完整原文派生实际提交稿，不按声纹片段拼接或剪裁；首段翻转时也恢复开头。精修使用同一整轮准入结果。

首段非主人且整轮没有恢复时，不进入普通对话响应，不再将被拦截的转写另存到环境文字区，也不提供环境记录界面或代理读取入口。身份待判期间不按 `empty_input`（空输入）结算；最终 `speaker_blocked`（声纹拦截）与真正空输入分开。活跃轮次原文不受闭段记录期限裁剪。

`admission_phase`（本轮准入阶段）和 `speaker_summary`（声纹摘要）通过既有状态接口传递。摘要与用户原话分开，进入主决策及后台分析上下文：记录首段身份、初判翻转、疑似外来声纹与判定原因。异声提示也可能来自声纹波动，不能确定具体哪几个词属于另一人。标注随状态变化更新，在下一次正常推理中读取，不按每个心跳单独唤起模型。

## 诊断日志与时间线

控制诊断写入既有服务日志，完整文字写入既有 `voice-server-llm-context.jsonl`（内容审计文件）的 `speaker_audit`（声纹审计记录类型）。沿用异步队列、轮转、容量预算及导出。既有 `VOICE_LLM_CONTEXT_AUDIT=0`（关闭内容审计）仍受尊重；关闭时无法从导出日志还原完整文字差异。

桌面导出时先在控制线程等待已入队的审计记录落盘，再使用现有日志打包入口；不会在音频线程等待文件写入。已结束输入不再接收迟到声纹结果；获准轮次提交时不为尚未完成的滚动异声分析额外延迟响应。

- 启动、设置提交、保存、实际应用和回滚记录声纹参数快照、生效边界及设置版本。
- 每次推理记录轮次、输入代次、激活编号、设置版本、心跳序号、音频采样区间、有效及新增人声、质量、耗时、评分分量、实际混合权重、正常及实际阈值、连续计数和准入阶段。
- 记录 `threshold_scope`（正常、轮内或跨轮阈值范围）、两种放宽量、开口资格快照、来源轮次、原始正常主人语音终点、进入与最长截止、候选边界撤销和最终资格交接；旧声纹回调仅作诊断，不另行授权。
- 原始识别、实际放行、最终提交及精修在内容修订或路由变化时记录完整文字、前一修订、字数和变化范围，避免每个心跳重复全文。
- 首段积累、推理、准入、识别定稿、模型派发、合成首音频、实际播放与最终结算保持可关联。合成首音频、播放器首帧和播放完成各自记录，不相互代替。
- 记录包含中文字段与枚举说明；不记录原始音频、声纹向量或系统凭据。写入异常不阻断识别和准入。

`GET /api/v1/speaker/status`（声纹状态接口）附带 `effective_settings`（实际运行设置）与 `parameter_effects`（参数生效范围）。`PUT /api/v1/product/settings/speaker`（声纹设置保存接口）保持原有字段，运行回执附带设置版本与生效范围。

## 模型、登记与资料

CAM++（上下文感知掩码声纹模型）为默认模型，使用独立官方特征前端及 192 维向量。旧 WeSpeaker（兼容声纹模型）的 256 维向量与资料不能混用；模型、特征指纹或资料格式不匹配时仍提示重新登记。本次修订不更换模型、声学前端或登记质量要求。

永久登记使用三段不同内容、每段 5–10 秒的正常语音，复用服务端采集和现有可调登记参数。默认每段最低 3 秒有效人声、合计 15 秒、最低 50% 人声占比、最大 0.5% 削波及最低 0.70 样本一致性。注册不能与实时采集并发占用同一设备或共享处理器；继续使用现有录制互斥。

资料由本机数据目录的 `speaker/registry.json`（注册索引）、`speaker/templates/`（模板）及 `speaker/probe.npy`（特征检查样本）管理。组件安装与修复继续经正式程序的组件列表执行。

设置页“主人声纹模板”默认折叠已保存的语音段落；展开后可查看各段的录制时间与主中心状态，并调整是否纳入主中心或删除模板。录制过程独立展开，显示三段录制进度和对应操作。
