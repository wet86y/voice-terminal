# 国内镜像与原站回退

桌面组件管理器默认优先使用国内镜像。资源的原始地址、版本、文件大小与 SHA-256（文件摘要）仍来自原有模型清单和运行依赖锁；切换传输渠道不会改变组件身份，也不会仅因镜像配置变化要求重新安装。

统一策略保存在 `config/download-sources.json`（下载来源配置）。Python（后端语言）、JavaScript（脚本语言）和 PowerShell（构建脚本）读取该配置；Rust（原生语言）在构建时嵌入同一份配置。调整策略后需要重新构建并发布完整程序，不能只替换已发布程序中的配置文件。

| 资源 | 首选来源 | 备用来源 |
| --- | --- | --- |
| Python（后端解释器）嵌入包 | 华为云镜像 | 官方发行文件 |
| PyPI（Python 包索引）固定安装包 | 清华镜像 | 原始文件服务器 |
| PyTorch（张量框架）处理器与显卡安装包 | 上海交大镜像 | 官方安装包服务器 |
| SmartTurn（语音结束判断）和 SenseVoice（整句识别精修） | 魔搭同摘要副本，固定镜像提交 | 当前锁定的原始模型仓库 |
| VoxCPM1、VoxCPM2（语音合成模型） | 魔搭同摘要副本，固定镜像提交 | 当前锁定的原始模型仓库 |
| 原本使用魔搭的模型 | 原有魔搭地址 | 保持原行为 |
| 唤醒模型、原生语音运行归档、已知摘要的更新安装器 | 公共下载加速入口 | 原始发行附件 |
| DSH（代理执行宿主）与 pnpm（插件包管理器） | 国内脚本包镜像 | 官方注册表 |
| Node.js（脚本运行环境）头文件 | 国内二进制镜像 | 官方头文件地址 |
| Cargo（原生包管理器）构建依赖与工具链 | 国内原生依赖镜像 | 官方来源 |
| tiktoken（分词器）当前词表 | 固定摘要的随包词表 | 缺失或损坏时使用既有字符估算，不隐式联网 |

安装计划显示来源域名，进度显示当前下载源及切换原因。桌面下载器对单次连接和无数据等待分别设置 12 秒与 20 秒上限，不设置整个大文件的总下载时限。来源失败后按顺序尝试备用地址；用户取消立即停止，不继续切换。

桌面断点身份由预期大小与摘要组成，同一内容可跨来源续传。摘要校验失败会移除无效暂存文件；候选内容通过完整校验后才进入既有事务安装。Python（后端语言）的维护工具逐来源重新下载暂存文件并校验，以避免混合未校验片段。已有组件、模型收据及两个运行依赖锁的内容身份保持不变。

## 包安装与用户配置

代理宿主安装时，实际注册表与头文件地址传入安装工具及其子进程。运行收据中的 `registry_url`（规范注册表）保持原值，`download_source`（实际传输来源）单独记录。公开注册表在网络、缺失版本或损坏归档等来源错误时回退；安装脚本的构建错误不盲目重新安装。

私有注册表不进入公开源回退。持久配置中的作用域注册表、认证及用户插件配置继续由包管理器使用；子进程环境中明确选择了私有注册表时保留该选择。代理启动时只为缺少插件管理配置的工作区追加公开备用源，不重新序列化已有用户补丁。已有显式插件管理配置保持原样。

注册表按环境变量、当前项目 `.npmrc`（包管理器配置文件）、用户配置和全局配置的顺序解析。构建代理宿主时按实际源码目录解析项目配置，避免运行脚本时所在目录遮盖源码自己的私有源。显式的私有 PyPI（Python 包索引）环境配置同样只使用该来源，不自动添加公开备用索引。

| 字段 | 中文说明 |
| --- | --- |
| `origin_prefix`、`mirror_prefix` | 原始地址与镜像地址的前缀映射 |
| `repo_id`、`revision` | 镜像仓库编号及固定提交号，不替换原资源版本 |
| `download_sources` | 安装计划中的来源域名；后端文件传输计划中为候选地址列表 |
| `registry_url` | 安装收据中的规范注册表来源 |
| `download_source` | 安装收据记录的实际传输注册表，不参与版本兼容判断 |
| `tokenizer` | 固定词表的原始地址、随包路径及摘要 |

esbuild（构建工具）优先使用安装的可选平台包，缺失时会先调用继承镜像配置的包管理器；该工具最后仍有硬编码原站兜底。node-pty（终端组件）的本机构建可能下载头文件，使用随安装尝试切换的头文件地址。第三方新增安装脚本仍需随依赖升级复查，不能承诺任意插件的自定义下载都受注册表设置约束。

## 开发安装与离线使用

前端依赖使用 `scripts/install-frontend.ps1`（前端依赖安装入口），支持镜像失败后回退；加 `-Offline`（离线）时只使用本地缓存。直接运行包管理器原生命令仍采用其自身配置。

运行环境构建工具与原生构建脚本已接入同一镜像策略。源码克隆在独立候选目录完成，成功后恢复官方来源记录，再按原规则检查固定提交。离线准备缺少源码、精确版本包管理器、解释器或依赖缓存时明确失败，不为补齐缺失内容改走在线安装。

## 验证边界

更新清单没有独立签名，因此继续直接从官方发行地址获取；只有拿到可信清单中的摘要后，安装器附件才使用公共加速。WebView2（微软网页运行引擎）保留官方在线及离线安装入口。

公共加速入口不等于境内托管，服务可用性会变化。自动回归使用独立临时目录与本机测试服务器，覆盖来源缺失、网页冒充文件、错误摘要、中断、续传、取消及原环境保留；真实镜像抽查只对实际读取的文件报告完整摘要。关闭 VPN（虚拟专用网络）的新设备全量安装需要另行实机验收，不能由本机小文件验证替代。

本轮测试命令、真实文件摘要验证、打包包含性和未完成验收项目见[国内镜像与原站回退验证](../testing/download-sources-20261018.md)。
