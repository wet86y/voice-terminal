# 设备连接与远程配对

从设置侧栏打开“设备连接”。本页选择本地运行或远程配对，管理设备名称、局域网配对及已登记连接。实现边界见[分布式设备运行架构](../architecture/distributed-device-runtime.md)，实际交付和验收范围见[当前交付记录](../releases/current-release.md)。

## 选择运行模式

在“运行模式”中选择“本地运行”或“远程配对”，再点击右侧“保存运行模式”。选择按钮只修改草稿，保存后才切换实际模式。

- 本地运行使用本机组件和设置。即使解释器或业务组件缺失，也可以先切换到本地，在“组件设置”中下载或导入资源；缺依赖时不会强行启动语音服务。
- 远程配对使用已配对服务端的业务设置与运行状态。本机麦克风、播放和连接偏好仍由客户端管理。
- 从远程切换到本地时，广播保持关闭；本机组件准备好后，再按需开启广播。

组件下载、导入及运行依赖说明见[组件设置与分类下载](component-settings.md)。分发器只安装、更新和修复程序本体，不代替组件列表下载安装业务组件。

## 设备名称

服务端的“局域网连接”卡片和客户端的名称卡片均提供右侧“重命名”按钮。名称支持中文，最多 32 个字符；留空保存可恢复基础随机名称。

名称用于发现和配对显示，真实设备编号保持唯一。显示名称允许重复，同一连接列表内的重名条目会按稳定设备编号添加数字后缀区分；重命名不会更换密钥或重新配对。

## 服务端开启广播与生成配对码

1. 保存本地运行模式，在组件设置中准备必要组件及当前启用功能。
2. 开启“广播并接受配对”。程序检查本机组件、实际运行就绪状态、SSH（安全外壳协议）服务及项目局域网规则；需要安装、启动或修复系统服务时，按项目弹窗确认，必要时再完成 Windows（操作系统）管理员授权。
3. 广播正常后，点击同一行的“获取配对码”，在客户端输入界面显示的六位码。配对码以弹窗有效期为准；成功配对、关闭弹窗或到期后失效。

未启用的可选组件不会阻塞广播。启动期间已有的广播意图会保留，实际就绪后才发布公告；组件未就绪时不会提前广播。关闭广播保留已有配对和项目网络许可。

“检查 SSH 服务”与简短状态位于同一行，供用户按需检查。进入设备页或普通刷新不触发系统 SSH 功能检查。客户端使用程序内置连接能力，不需要为连接服务端另行启用本机 SSH 服务端。

## 客户端搜索与配对

1. 保存远程配对模式。
2. 在“远程配对”卡片右上角点击“搜索设备”，从“选择服务端”下拉框选择目标。
3. 在选择框下面输入服务端显示的六位配对码，点击同一行的“连接”。如服务端请求公钥登记授权，在服务端完成确认。

该卡片还收纳服务端 SSH 状态及“在线语音在本机合成并播放”“压缩远程音频”两个滑块开关。压缩使用 Opus（音频编码），仍属于需要音质及识别对照的实验能力。

已配对目标显示在“服务端连接状态”卡片中。未配对设备只作为配对区域的搜索目标，不会加入已配对连接列表。连接行左侧显示名称和简短状态，右侧提供连接或断开；刷新位于整体卡片右上角。普通断开后再次连接无需重新输入配对码。

## 入站客户端与连接状态

服务端的“入站客户端”卡片容纳已登记客户端，刷新位于右上角，连接条目与客户端的服务端连接卡片采用相同布局。状态含义如下：

| 状态 | 含义 |
| --- | --- |
| 已连接 | 已建立实际认证管理连接或核心设备会话。 |
| 在线 | 已登记、当前断开，但局域网公告可发现，可由客户端发起或恢复连接。 |
| 离线 | 已登记，完成局域网搜索后未发现对应公告。 |
| 待检查 | 当前无法获得可靠发现结果，不把未知状态当作离线。 |
| 待清理 | 配对授权已撤销，系统公钥清理尚未完成；保持授权关闭，可重试移除。 |

客户端的已配对服务端被发现且可用时显示“可连接”。发现公告只提供可用性提示，不代表已经完成认证，也不能新增配对授权。入站客户端列表不再单独标记“当前语音设备”。

## 断开与移除

普通断开保留密钥、地址和配对资料。客户端主动断开会暂停自己的自动重连；服务端点击“断开”会先通知客户端保存暂停状态，得到认证确认后关闭会话。之后由客户端点击“连接”恢复。客户端尚未确认时，本轮请求结束并提示刷新后重试，不把未确认请求显示为成功。

移除只在断开状态提供，并需在项目弹窗确认：

- 客户端移除服务端：清理该条目在本机保存的密钥及连接资料；再次连接需要重新进入配对流程。
- 服务端移除客户端：先持久撤销配对授权，再清理与该设备标记和预期公钥同时吻合的系统授权行，最后删除登记。系统清理被取消或失败时保留“待清理”条目，可点击“重试移除”。

只有已认证服务端明确确认原配对失效时，客户端才自动清理对应旧资料。普通认证失败或主机密钥变化会暂停连接并保留旧信任；在配对区域重新搜索，使用有效配对码验证后再替换。服务端移除登记时若客户端已离线，客户端收不到可信通知，后续认证被拒时按上述流程重新配对。普通网络中断仍按既有退避节奏重连，局域网广播无法触发密钥清理。

新增的断开与配对失效通知需要两端均更新到支持该流程的程序。显示为同一产品版本时，也应使用本轮分发器更新尚未包含这些功能的旧程序。

## 远程模式下的组件页面

远程组件页显示服务端安装及运行状态，隐藏部分进程内存、提交内存和显存占用，完整统计在服务端查看。客户端不提供组件下载、批量导入及模型导入按钮；音色参考录音的授权上传和已有设置操作继续保留。

需要准备客户端本机组件时，先在设备连接页保存本地运行，再进入组件设置。此时显示本机正式组件目录，下载与导入不再等待服务端映射。广播开启仍需通过本机就绪校验。
