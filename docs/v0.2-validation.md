## 本次新增能力的确定性验证

- `DirectStreamingPolicy` 在剩余音频超过 2 秒时仍继续发送，短尾和无标点文本通过 flush 输出；`PlaybackWindowPolicy` 的首段、窗口边界、片段完成、超时、取消唤醒、有界队列和供应商失败保持原有业务含义，并在提供设备位置估计时用 `output_estimated_ms` 控制窗口、保留 callback `played_ms` 计数。
- Bidi provider 使用单接收任务和可复用连接，覆盖多轮 flush、cancel 屏障、取消超时重连、迟到音频/字幕隔离、2205 关联片段重试、无关联错误和 64 MiB spool 限制。
- 播放器覆盖部分 chunk 顺序、补零不计入输出、设备延迟估计、旧 playback key 不影响新轮和原子 `stop_and_snapshot`。
- `SpeechAlignment`/`DeliveryResolver` 覆盖词中截断、重复文字、迟到/缺失字幕、MiniMax Bidi `timestamped_words`、累计快照、句子局部时间归一化和无法定位时的保守 `uncertain`/`unheard` 结算；历史重复终止、连续插话、首音前取消和 TTS 失败均保持幂等。
- `AudioPreprocessor`/`BargeInGate` 覆盖静音、脉冲噪声、短候选、持续真人语音、预录首字、AEC 降级/反向参考中断时禁用受保护自动插话和 10 ms 帧长度。播放器另有 `audio.device_latency_ms` 保守设备尾部估计；当前环境已安装 `aec-audio-processing==1.0.1` 与 `webrtcvad-wheels==2.0.14`，完成导入、独立近端 VAD 和帧长度 smoke test，但这不是声学效果验收。
- 前端覆盖 `turn.interrupted` 即时状态、`turn.completed` 唯一历史写入、delivery 展示、重连快照和旧 payload 缺少 delivery 时的不可用提示。

## 长语音截断修复验证（2026-09-05 夜间）

- MiniMax 接收改为独立顺序 PCM 缓存，内存阈值 8 MiB，超出后落盘；慢播放不再通过 64 块队列阻塞网络读取。结束和取消释放缓存。
- `is_final` 只用于确认当前文本分段完成；仅 `task_finished` 确认整轮合成成功。部分音频后断线或限流保留已收 PCM，播放后报告 `DEGRADED`。
- v0.2 pacing 等待当前分段完成，并按全部已接收音频减去已播放音频计算提前量；修正以前其他分段的 PCM 会放行新文本的问题。v0.1 保留完整回答文字，播放排空期限随缓存时长调整。
- 回归覆盖超过 8 MiB 的顺序输出、缓存失败、分段/整轮完成的区分、20 秒缓存的异常排空、停止释放落盘缓存及下一轮拒绝旧音频。实施前的 88 项回归继续保留；合并本次 Bidi、AEC、独立 WebRTC VAD、门控、首音前插话窗口、时间线、字幕、历史和前端状态测试后，Python 完整套件为 120 项通过。本次还通过 compileall 和 diff 检查。

## 真实 MiniMax Bidi 字幕与取消 smoke test（2026-09-06）

在当前 `.env.local` 配置的 API 域名和凭据上，使用 `speech-2.8-hd`、32 kHz 单声道 PCM、`subtitle_enable=true` 和 `word_streaming` 做了短文本探针；API Key 和完整文本未写入日志。实际返回的字幕位于 `data.subtitle`，包含 `text`、`time_begin`、`time_end`、`text_begin`、`text_end` 和累计增长的 `timestamped_words`；词项包含 `word`、`time_begin`、`time_end`、`word_begin`、`word_end`。每个 `sentence_start` 后时间从 0 重新计，适配器使用该事件时的累计 PCM 作为句子基准。当前解析器已覆盖这些字段，并按词索引替换重复快照。

取消探针在收到首个旧 PCM 后发送 `task_cancel`：服务端在 `task_canceled` 之前仍可能继续推送已经排队的旧帧；直接协议探针观察到约 69 KiB 的迟到旧音频。当前 session 在取消请求置位后不再写入本地 spool，收到确认后保留连接；通过 session 类的复用测试，取消确认约 62ms，随后第二代文本成功 `task_flush`，连接生命周期编号保持不变。这个结果验证了 Bidi 取消屏障和本地 generation gate 的职责分离。

这属于真实服务 smoke test，不等同于完整服务验收。尚未完成计划要求的至少 3 轮正常 flush、至少 3 次 cancel 后新轮、无标点短尾、2205 真实返回结构和长期稳定性统计。
