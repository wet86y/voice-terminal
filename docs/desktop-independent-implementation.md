# 桌面独立启动与按需语音环境实现

> 本文保留旧渠道架构的历史实现与验收记录。当前入口、路径和安装行为以[统一正式程序与分发安装器](unified-product-installer.md)及[当前交付](current-release.md)为准。

版本：**0.9.0**。开发位置：`D:\项目开发\语音前端`，实现时使用 `main`（主线）。本文保留该轮实现与验收证据，文件大小、摘要和测试数量均代表当时结果；最近一次重建和当前测试入口见[当前开发与分发交付](current-release.md)。该轮完成程序改造、开发与分发构建和少量定向检查；程序自动更新仍为占位区域。

## 交付和启动

公开交付一个 `VoiceTerminal.exe`（程序入口），当前为 **36,864,000 字节，约 35.2 MiB（兆二进制字节）**。界面静态资源直接内嵌，本体代码、配置、工具、少量预编译依赖及说明作为压缩资源内嵌。首次展开无需本体发布地址；不组装完整 Python（后端环境）、模型、DSH（代理执行宿主）或固定 WebView2（网页引擎）。

启动顺序：

1. 检查当前用户与系统的 WebView2 Evergreen Runtime（自动更新网页引擎）。缺失或创建失败时，原生提示提供微软在线引导器、离线安装页面和退出；安装后重新启动程序。
2. 使用现有启动动画，进度条下按状态展开选择工作区、重选、重试、取消、进入组件管理和退出按钮。系统选择器负责选择文件夹，展开进度与错误留在启动画面。
3. 初始化工作区，校验并事务展开内嵌本体，补齐当前入口的实际摘要。压缩资源不包含入口自身，避免摘要循环。相同版本但内嵌内容变化时也重新展开，保留已有组件登记。
4. 无私有 Python 或基础依赖未就绪时进入原生管理界面。语音、业务设置、历史和任务入口说明配置前置条件。语音环境就绪后在同一窗口启动业务界面；后端停止时可以回到组件管理。

微软安装入口使用[官方在线引导器](https://go.microsoft.com/fwlink/p/?LinkId=2124703)和[官方安装页面](https://developer.microsoft.com/microsoft-edge/webview2/#download-section)。程序不会安装、卸载或修改系统引擎。

迁移基础流程由原生实现执行，不再以 Python 为前置条件。已知配置路径按固定规则重建，进程与端口状态重新生成；只有目标管理页或认证业务页实际完成加载后才写入就绪记录，随后确认定位切换和旧目录清理。大规模迁移本轮未实机验收。

## 资源管理与语音环境

原生宿主承担资源清单、校验、下载、目录与压缩包导入、DSH 提取、任务记录和事务恢复。缺失模型／DSH 卡片显示下载、导入、跳转；完整组件保留详情。任务显示阶段、进度、取消、重试及错误原因。

- 模型目录导入按固定文件摘要检查；ZIP64（大文件压缩格式）批量导入先展示识别结果，确认后整体预校验、逐资源事务安装，完整重复项跳过。
- GitHub（代码托管平台）与 Hugging Face（模型平台）固定文件通过 DesktopUpdateKit（桌面下载组件）的静态 C ABI（调用接口）下载，支持摘要、进度、取消、重试和跨进程续传。
- ModelScope（魔搭模型平台）下载使用私有 Python 中的独立 SDK（平台开发库）进程，固定版本、精确文件白名单和匿名访问；安装内容预览同时包含其下载依赖。
- 官方 DSH 固定为 `0.2.0-rc.2`，验证安装器摘要，通过固定完整 7-Zip（压缩工具）提取 NSIS（安装包格式）与内部负载，保留 Electron（桌面应用框架）归档及原生资源。程序不执行官方安装器。已有物理运行包继续按原清单识别。

Voice Server（语音服务）卡片提供配置、导入、说明，分别显示解释器、基础依赖和服务就绪状态。基础解释器为 **CPython（官方实现）3.12.10、Windows x64（64 位）**，位于 `runtimes/python`（私有后端环境）。

配置过程为检查可复用资源、展示内容、暂存组装、下载缺失项、校验、事务启用。复用先检查已验证程序缓存，再检查官方安装记录中的本机解释器和依赖；版本、架构、CPU（中央处理器）构建类型、安装记录或动态库来源不合格的内容重新下载。普通虚拟环境、Conda（环境管理发行版）、商店执行别名和外部链接不直接复制。

固定运行清单 `config/runtime/voice-runtime.lock.json`（依赖锁）含解释器与 **107 个依赖条目**的版本、大小、摘要及分组。工作进程使用标准库组装 wheel（预编译依赖包），不要求用户设备编译或系统 pip（依赖安装工具）。私有搜索路径使用相对路径，可整体移动。少量缺少直接可用官方 Windows 预编译包的依赖在开发构建阶段从已验证基线生成并随本体携带。

| 共享依赖组 | 用途 |
| --- | --- |
| `voice-core`（语音基础） | 业务服务、配置、网络和音频基础库 |
| `torch-cpu`（张量框架中央处理器） | Paraformer、FSMN-VAD、SenseVoiceSmall（识别、活动检测、精修） |
| `onnx-cpu`（模型推理中央处理器） | SmartTurn、WeSpeaker（结束判断、声纹）及预处理 |

| `modelscope-download`（平台下载） | ModelScope 固定文件下载工作进程 |

模型下载计划合并所需依赖组；完整匹配项复用，损坏环境不能直接跳过配置。导入仅含模型文件的离线包时，显示文件已安装、运行环境待配置。语音环境界面的导入入口当前选择已准备好的环境目录；压缩环境导入基础逻辑保留在原生实现中。

## 显卡环境和兼容

用户显卡环境登记为工作区内 `runtimes/python-gpu`（独立显卡后端环境）的相对路径。本体展开 `data/docs/模型运行环境配置指南.md`（代理配置说明），列出固定中央处理器版本、现用英伟达 CUDA（显卡计算平台）兼容组合、目录、模型文件、检测和恢复方法。

登记／重新检测按模型检查解释器、共享进程依赖、显卡后端、必要文件和实际推理。通过的模型才开放 GPU（显卡）选项；保存环境及模型指纹，内容变化后重新检测。工作进程按登记解释器启动，显卡启动失败恢复中央处理器并显示原因。

旧 `cu128`（CUDA 12.8）私有运行包和已有模型／DSH 清单继续识别，不自动用中央处理器组合覆盖。开发版继续读取项目资源与数据。完整中央处理器模型组和真实显卡矩阵本轮均未验证，指南中的显卡唤醒组合属于兼容候选。

### 关键接口字段

| 类型／字段 | 中文说明 |
| --- | --- |
| `LaunchContext` | 启动上下文，区分桌面路径解析与语音环境就绪 |
| `DesktopPort` | 桌面原生接口，提供初始化、资源、解释器和显卡环境操作 |
| `ResourceStatus` | 文件安装、运行依赖、可启动能力分别报告 |
| `ResourceJob` / `import_preview` | 资源任务／批量导入识别结果 |
| `ModelCapability` | 各模型中央处理器与显卡能力及不可用原因 |
| `embedded_payload_sha256` | 已展开本体的内嵌资源摘要 |
| `environment_fingerprint` / `models_fingerprint` | 显卡环境／模型文件版本指纹 |
| `interpreter_version` / `gpu_hardware` | 解释器版本／显卡硬件快照 |
| `endpoints` / `endpoint_revision` | 实际端点表／端点版本；沿用已有动态端口机制 |

宿主启动时独占绑定首选端口，端口已占用时由系统分配空闲回环端口；语音工作进程先取得套接字再加载模型。DSH 使用系统临时端口并从标准输出读取实际地址，含令牌的地址不进入普通日志。组件重启后端点版本变化，宿主刷新依赖客户端与连接。

## 构建命令和产物

```powershell
npm run frontend:build       # 前端类型检查与构建
npm run desktop:build        # 开发渠道，构建主程序和根启动入口
npm run desktop:publish      # 本机开发程序覆盖发布
npm run desktop:dist         # 正式分发单 EXE（程序入口）
npm run desktop:dist -- -Qualification # 独立验收单 EXE（程序入口）
```

`desktop:dist`（分发构建）准备工具、界面及内嵌本体，静态链接必要 C++（原生代码）运行库，最后校验渠道与本体摘要。`-SourceBase`（后续发布来源）与 `-SkipDesktopBuild`（复用已编译宿主）是该轮当时的 `desktop:dist` 参数，渠道改造后已从 `scripts/distribute-desktop.ps1` 移除；当前开关为 `-Qualification`、`-SkipProductBuild` 与 `-SkipInstallerBuild`，见[统一正式程序与分发安装器](unified-product-installer.md)。

构建依赖当前已验证的开发基线、锁定下载组件和压缩工具。少量随包依赖及私有解释器动态库从该基线准备；从干净源码设备复现构建前需要准备这些开发资源。本轮未执行干净构建机验收。
