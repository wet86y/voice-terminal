# 工作区切换与迁移加载界面统一

工作区辅助进程直接嵌入 `apps/desktop/boot/index.html`（共享加载页），与安装器、桌面启动使用同一图标、布局和 `startup.css`（加载样式）。切换及迁移显示“程序迁移中”、当前处理阶段和进度条；失败仍在同一画面显示原因。已移除独立的原生白色进度窗口。

`role=workspace-task`（工作区事务职责）只开放读取状态、取消和退出，组件管理、跳过和安装入口均隐藏。复制阶段允许取消；目标启动校验及原目录清理阶段禁用取消和退出。关闭窗口在可取消阶段请求取消，等待后台返回后退出，不直接终止复制线程。进度窗口使用目标 `tmp/process`（临时进程目录），避免清理原工作区时占用原目录，也避免后续迁移复制界面缓存。

## 速度及进度调整

目前迁移采用四个复制线程和每线程 1 MiB（兆二进制字节）缓冲区。每个文件都保留暂存、落盘、SHA-256（内容摘要）回读校验和校验后启用；目标真实页面就绪后才清理原受管目录。这些操作有实际磁盘开销，尤其是同盘迁移或大量小文件。

本次将每文件两次父目录创建及重复目录检查改为派发前按唯一父目录集中创建，逐文件安全路径检查和启用前路径复核继续保留。复制阶段进度同时统计源文件读取与目标回读校验；字节总量是两次处理量之和，复制阶段达到 100% 表示两部分均完成。文件统计、路径更新和目标启动阶段使用动态进度条。进度回调限制为约每 100 毫秒一次；扫描期间也响应取消。

尚未测量真实完整工作区的优化前后总耗时，不能据此承诺固定加速倍数。剩余开销包括落盘、完整内容校验、目标启动和原目录清理。
