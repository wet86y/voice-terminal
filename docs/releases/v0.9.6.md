# Voice Terminal（语音终端）v0.9.6

代码版本：`0.9.6`。本版本先更新仓库本机正式程序与独立分发安装器；GitHub（代码托管平台）发行资产暂时保持 0.9.5，尚未创建或覆盖远端发行条目。

## 主要变更

- **强制兼容处理**：程序包新增随本体固定分发并按摘要核对的兼容性组件。安装器与本地发布在交接正式程序前执行同一流程：修复环境、移除确认非法的受管资源、回退无效设置、重新准备必需组件并复核启动条件。失败时保留新版本体和修复进度，安装器继续完成修复，不恢复旧的不兼容组合。
- **设置与历史资料保护**：未知或损坏的设置按当前安全默认值重建；故障声纹档案、音色资料和活动会话先归档，再修复引用与默认数据。归档使用稳定事务记录，处理中断后可继续完成。
- **资产复用**：版本升级优先复用已通过摘要和内容核验的模型、运行环境及可选组件。缺少可选组件仍不阻塞启动；只有强制兼容检查确认受管必需资源失效时才清除并修复。
- **语音处理恢复**：修复设置并发保存与计算设备切换之间的覆盖竞争，避免运行中监听在异步切换期间提前恢复。
- **双路识别复用**：离线精修继续使用已安装的离线识别组件与权重，不为新双路配置重复下载资源。流式与离线精修仍按各自模型实现及权重要求运行。
- **分发器起点检查**：Node（脚本解释器）仍由分发器现有起点校验逻辑负责，本版本不增加额外 Node 探测或安装流程。
