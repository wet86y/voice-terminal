# 正式程序与分发安装器交付

产品版本 `0.9.0`（产品版本）使用 `build`（构建编号）区分正式构建。本机正式程序与普通分发安装器共用 `product-ee05746262971e1d`（正式构建编号）的程序包；程序包包含 340 个固定文件，大小为 101,342,287 字节，SHA-256（完整文件摘要）为 `aafa51fd9d8441a1d7759536154d8381ead4a6d0059c979e0bab720c4e7c7789`。分发安装器大小为 110,682,112 字节，摘要为 `16fc5237eb51ac8070afc058f0055e730bf4a4f6acb84c34929e948eb5446719`；构建戳、交付记录与本机正式程序包摘要一致。该安装器为普通交付，`qualification=false`（隔离验收开关关闭）。

程序和安装器的结构、组件门槛与恢复规则见[统一正式程序与分发安装器](../guides/unified-product-installer.md)。测试命令、重建步骤和用户验收顺序统一放在[测试入口](../testing/operations-and-quality.md)；历史专项证据按主题收录于[测试目录](../README.md#测试)。

## 近期变更

- **DSH（代理执行宿主）与插件升级到 `0.2.1-rc.2`（宿主候选版）**：程序包锁定上游版本及来源提交，项目插件升为 `0.2.1`（插件版本）；适配记录升级至格式 2，保留桥接协议 `2.0` 并核验桥接、唤醒任务及双语元数据四个导出入口。应用本体更新保留当前宿主目录，组件页显示目标版本后由用户手动下载更新。RC2（第二个候选版）功能、插件兼容和分发升级结果见[DSH RC2 升级验收](../testing/dsh-rc2-upgrade-20261017.md)及[DSH 包分发与兼容指南](../guides/dsh-npm-distribution.md)。
- **试听后合成变慢的交付修复**：覆盖安装自动离线应用随包原生补丁，应用、语音运行组件和模型登记在同一事务启用；本地启动核对目标版本，避免新版应用沿用旧原生程序。实际运行身份新增目标版本及摘要匹配日志。现场证据与回归见[试听后合成变慢与原生组件覆盖升级](../testing/tts-preview-upgrade-20261017.md)。
- **本地首音直接播放**：VoxCPM1、VoxCPM2 的起播音频储备固定为 0，首块 PCM（脉冲编码音频）到达且播放许可通过后，下一次设备回调立即播放，不等待首句合成结束。欠载后的恢复储备独立装配；运行规则见[本地首音直接播放](../guides/tts-runtime.md#本地首音直接播放)。
- **语音性能取证补齐**：记录实际程序构建、原生程序路径与完整摘要、安装收据匹配、首音就绪→入队→设备提交、音频块抵达间隔及原生汇总计时；修正显卡进程结构、原生日志转发延迟和预建会话关联，显卡采样移入后台线程。块抵达间隔不等于播放停顿，实际欠载另有统计。字段及边界见[本地 TTS 可观测性](../guides/local-tts-observability-20261015.md)。
- **组件设置与分类下载**：设置页和启动前管理器共用“用途分类 → 组件 → 组件详情”三级界面，分类下载清单展示资源状态与共享依赖，确认后协调并行下载；DeepSeek 和 MiniMax 的在线密钥及账户用量入口位于对应详情。TTS（语音合成）迁移程序已与当前随包 audio.cpp（本地语音运行程序）版本及摘要对齐。
- **Voice Server 可选 GPU 运行依赖**：三卡片分别管理必需 CPU（中央处理器）依赖、可选 audio.cpp 和可选 GPU（图形处理器）依赖。GPU 安装在同一解释器内替换 PyTorch（深度学习框架）与 torchaudio（音频扩展），Paraformer（流式识别）、SenseVoice（语音精修）和 CAM++（声纹识别）继续复用原权重；缺少可选 GPU 依赖不阻塞 CPU 启动。相同权重的 CPU/CUDA（显卡计算接口）实测见[GPU 运行依赖实现与验证](../testing/voice-gpu-runtime-20261017.md)。
- **旧工作区升级兼容**：旧模型与总清单摘要不一致且缺少有效安装收据时，升级过程保留模型、总清单、组件登记和声纹资料，暂缓 CAM++（声纹嵌入模型）迁移并继续更新程序本体；模型完整性与启动门槛仍执行。修复旧模型后再次安装可继续迁移。合成旧布局场景的验收见[升级兼容性验收](../testing/upgrade-compatibility-20261016.md)。
- **默认扬声器跟随系统**：Windows（操作系统）播放使用 MME（多媒体扩展接口）的 WAVE_MAPPER（系统声音映射器）端点，使打开的播放流跟随系统默认输出设备；源码与当前正式程序中的模块摘要已核对。双设备听感切换仍待现场确认。
- **资源摘要复核**：组件原地换版后，同一字节数的文件也按新内容更新模型清单摘要；保留模型按组件收据重新核验。外部工具以相同大小并保留旧时间戳改写受保留模型时仍有单独的 P3 风险，详见[最近提交审阅](../testing/recent-code-review-20261016.md)和[当前已知问题](../testing/known-issues.md)。

## 最新验证概况

- 本轮后端全量测试 1,594 项通过、3 项跳过；最终分发与启动日志定向回归 34 项通过；首音与性能日志相关定向回归此前 179 项通过。前端类型检查和正式构建通过。
- 文档链接检查通过，核对 323 个链接；本机正式程序原生完整校验通过。分发安装器与本机使用相同的 `b7eec0e6…` 程序包 SHA-256（安全散列摘要）；包内包含 `config/runtime/voice-gpu.lock.json`（可选显卡依赖锁）。
- 原生公共模块先前全量 98 项通过、11 项按既有配置默认忽略；本轮新增运行时定向回归后共 99 项通过、11 项忽略。另有 Python（运行环境）依赖工作器及显卡环境定向测试 47 项通过、桌面命令测试 22 项通过、前端 Vitest（前端测试框架）325 项通过，正式界面构建通过。
- 试听后真实模型重测：293 字、19 段，平均实时因子 0.6277，最大音频块抵达间隔 85 毫秒，播放器欠载为 0；完整解码的大型图容量 256，正式流式阶段全部回到 16。
- 真实旧组件覆盖升级 20 项检查通过：现场同摘要旧程序自动替换为当前目标，28 个原生文件逐项匹配，模型总清单与应用登记一致，5 个保留样本及源组件内容不变。
- 后端模型更新与资源门禁专项 18 项通过。
- 旧布局升级覆盖无收据、缺失新元数据及失效旧清单等隔离场景，包括重复安装、文件保留、完整性拒绝和修复后恢复。
- 本机正式程序本体原生完整校验通过；普通安装器与统一程序包的构建编号及 SHA-256 摘要一致。GPU 依赖锁随程序发布；本次发布未触发可选 GPU 依赖下载或显卡运行环境切换。
- DSH（代理执行宿主）RC2（第二候选版）构建、插件专项和桌面包回归结果与分发升级边界见[DSH RC2 升级验收](../testing/dsh-rc2-upgrade-20261017.md)。本轮全量前端测试结果包含 19 项失败（分布于四组未修改的界面夹具或断言）；修改涉及的资源安装弹窗测试 6 项通过，正式前端构建通过。全量前端测试未达到全绿，不能据此声称所有前端测试通过。

这些结果覆盖项目内和隔离合成数据验收，不代表干净设备、不同 Windows 版本、无显卡设备、真实麦克风音质或真实模型服务均已验收。
