## 近期变更

### 0.9.8 定时任务间隔与后台服务维护（2026-10-25，仅本机更新）

定时任务新增 1 分钟至 24 小时间隔及有限触发次数，设置页复用统一时间选择器和滑动循环开关，DSH（代理执行宿主）工具同步支持配置；声纹身份未知时会继续核验，仍无法确认的轮次不会进入对话；后台服务改用受管进程生命周期与统一系统显示身份。用户说明见[0.9.8 更新说明](v0.9.8.md)，本机更新与验收见[同版本本机覆盖更新记录](../testing/local-delivery-0.9.8-20261025.md)。

### 0.9.8 持续倾听、声纹筛选与播报修订（2026-10-24，已公开发行）

语音助手可按当前对话语境继续倾听并结合后续输入与后台变化自然衔接；播报支持取消并平滑替换。声纹筛选先核对首段再按整轮判断，相关参数及模板列表收进折叠区域；热词设置布局更紧凑并适配窄面板。旧版当前会话的环境记录页已移除；完整条目见[0.9.8 发行说明](v0.9.8.md)，本机更新、分发安装器和公开资产验收见[0.9.8 交付记录](../testing/release-0.9.8-20261024.md)。

### 0.9.7 热词精修、组件维修交接与同版本重发（2026-10-23，已公开发行）

双路精修改用热词增强离线识别模型，主路与悬浮字幕保持主流式文本；参考转写支持标点和流式回退。热词词表支持条目与 JSON（轻量级数据交换格式）批量编辑；本体更新后的组件维修和随包离线兼容迁移由正式程序接续处理。用户需了解同版本重发及旧版手动安装要求，见[0.9.7 发行说明](v0.9.7.md)；本机更新及公开资产验收见[0.9.7 发布记录](../testing/release-0.9.7-20261023.md)。

### 0.9.6 热词增强精修与主路隔离（2026-10-23，仅本机更新）

主路保持原有 SmartTurn（轮次结束判断）流程，VAD（语音活动检测）闭段只提交离线精修，单独切换双路不停止监听或重建主模型。精修采用热词增强模型并处理累计标点；正文与悬浮字幕始终保留主流式文本。音色参考转写按双路开关选用路线，两路均处理标点且隔离热词。热词管理支持条目编辑与流式替换；本机当前更新进一步提供完整词表 JSON（轻量级数据交换格式）批量编辑，详见下文及[v0.9.6 发行说明](v0.9.6.md)。实际交付与测试见[本轮验收](../testing/contextual-dual-pass-20261023.md)。

### 0.9.6 热词列表与 JSON 词表编辑（2026-10-23，仅本机更新）

热词列表限制可见高度并支持滚动，改为每页 20 条；首尾页码固定，当前页附近显示连续数字，中间跨度用省略号收敛，数量与分页同处底栏。移除流式热词试测组件，导入词表按钮移到添加热词右侧。词表弹窗以当前已保存的完整 JSON 数组作为起始内容，允许复制粘贴后批量修改；保存时沿用现有词表规则校验并整表写入，别名和排除词可省略。

### 0.9.6 按需完整性校验、兼容处理与启动修复（2026-10-22）

设置页可按本机程序版本执行完整性校验，检查更新继续单独获取最新发行。安装和更新会统一核对设置及受管组件，并复用有效模型与运行环境；缺少可选组件仍可启动。组件更新时保留当前页面并持续显示恢复进度，修复首次启动白屏、维护状态中断、设备切换与设置保存互相覆盖等问题。完整条目见[v0.9.6 发行说明](v0.9.6.md)。

### 0.9.5 CPU/GPU 设备热切换与模型进程回收（2026-10-21）

Paraformer（流式语音识别）、emotion2vec（情绪模型）和 CAM++（声纹模型）可从详情页在中央处理器和图形处理器之间热切换。运行状态卡承接后台加载、预热、核验、失败回滚与监听恢复；Paraformer 的流式推理进程独立回收，已启用的离线精修与主路使用同一设备。实现范围、接口字段和状态核验见[设备热切换生命周期](../guides/compute-device-hot-switch.md)及[v0.9.5 发行说明](v0.9.5.md)。

### 0.9.4 音色试听、语音调度与对话修复（2026-10-20）

MiniMax 在线音色选择支持试听和打开官方音色库。用户主动触发的在线试听、本地设计试听和已保存样音播放不再受被动静默时段阻塞；普通助手播报仍受静默策略控制。另包含 SmartTurn 放行待播 TTS、跨轮次人格修订、热词入口修正、DeepSeek 模型名更新、影子推理中文约束，以及避免重复捕获已消费截图的修复。完整变更见[v0.9.4 发行说明](v0.9.4.md)。

### 0.9.2 日志、计时与语音合成修复（2026-10-18）

桌面端新增运行日志压缩包导出；主界面感知延迟计时改用服务端事件时间，并在窗口恢复前台时校正；一代 TTS（文本转语音）修复声纹过滤与热词同时启用时的正文契约，并在中止或判废后有界重试原生资源释放。公开发行通过 12 组隔离安装与工作区验收。现场播放失败日志显示生成音频超过 9 秒保护预算；转写对照能复现同类超预算输出，但现场参考转写原文和原始波形不可得，因此没有宣称模型侧首因已经完全锁定。详细说明见[0.9.2 发布验收](../testing/release-0.9.2-20261018.md)及[一代 TTS 调查记录](../testing/tts-v1-playback-investigation-20261018.md)。

### 0.9.1 更新交接修订与重新发行（2026-10-18）

分发器接受已下发 0.9.0 程序生成的一次性编号，并兼容旧程序正常退出的时序；保留进程身份、工作区、安装器摘要与一次性配置检查。更新页面拆分版本、操作、下载进度和发行说明，修复按钮挤压及取消按钮被错误禁用。重新构建的线上安装器已通过真实公开 0.9.0 程序包的两种退出时序验收；版本标签、四项发行资产及公开最新更新入口已同步核验。旧版程序重新点击“检查更新”即可获取新清单，详见[应用更新交接验收](../testing/app-update-handoff-20261018.md)。

- **试听后合成变慢的交付修复**：覆盖安装自动离线应用随包原生补丁，应用、语音运行组件和模型登记在同一事务启用；本地启动核对目标版本，避免新版应用沿用旧原生程序。实际运行身份新增目标版本及摘要匹配日志。现场证据与回归见[试听后合成变慢与原生组件覆盖升级](../testing/tts-preview-upgrade-20261017.md)。
- **本地首音直接播放**：VoxCPM1、VoxCPM2 的起播音频储备固定为 0，首块 PCM（脉冲编码音频）到达且播放许可通过后，下一次设备回调立即播放，不等待首句合成结束。欠载后的恢复储备独立装配；运行规则见[本地首音直接播放](../guides/tts-runtime.md#本地首音直接播放)。
- **语音性能取证补齐**：记录实际程序构建、原生程序路径与完整摘要、安装收据匹配、首音就绪→入队→设备提交、音频块抵达间隔及原生汇总计时；修正显卡进程结构、原生日志转发延迟和预建会话关联，显卡采样移入后台线程。块抵达间隔不等于播放停顿，实际欠载另有统计。字段及边界见[本地 TTS 可观测性](../guides/local-tts-observability-20261015.md)。
- **组件设置与分类下载**：设置页和启动前管理器共用“用途分类 → 组件 → 组件详情”三级界面，分类下载清单展示资源状态与共享依赖，确认后协调并行下载；DeepSeek 和 MiniMax 的在线密钥及账户用量入口位于对应详情。TTS（语音合成）迁移程序已与当前随包 audio.cpp（本地语音运行程序）版本及摘要对齐。
- **Voice Server 可选 GPU 运行依赖**：三卡片分别管理必需 CPU（中央处理器）依赖、可选 audio.cpp 和可选 GPU（图形处理器）依赖。GPU 安装在同一解释器内替换 PyTorch（深度学习框架）与 torchaudio（音频扩展），Paraformer（流式识别）、SenseVoice（语音精修）和 CAM++（声纹识别）继续复用原权重；缺少可选 GPU 依赖不阻塞 CPU 启动。相同权重的 CPU/CUDA（显卡计算接口）实测见[GPU 运行依赖实现与验证](../testing/voice-gpu-runtime-20261017.md)。
- **旧工作区升级兼容**：旧模型与总清单摘要不一致且缺少有效安装收据时，升级过程保留模型、总清单、组件登记和声纹资料，暂缓 CAM++（声纹嵌入模型）迁移并继续更新程序本体；模型完整性与启动门槛仍执行。修复旧模型后再次安装可继续迁移。合成旧布局场景的验收见[升级兼容性验收](../testing/upgrade-compatibility-20261016.md)。
- **默认扬声器跟随系统**：Windows（操作系统）播放使用 MME（多媒体扩展接口）的 WAVE_MAPPER（系统声音映射器）端点，使打开的播放流跟随系统默认输出设备；源码与当前正式程序中的模块摘要已核对。双设备听感切换仍待现场确认。
- **资源摘要复核**：组件原地换版后，同一字节数的文件也按新内容更新模型清单摘要；保留模型按组件收据重新核验。外部工具以相同大小并保留旧时间戳改写受保留模型时仍有单独的 P3 风险，详见[最近提交审阅](../testing/recent-code-review-20261016.md)和[当前已知问题](../testing/known-issues.md)。
