# Voice Terminal（语音终端）v1.0.0

## 新增与改进

- 本地语音采用 AnifLive（本地语音引擎）。可从本地文件夹或公开模型仓库导入配对权重、参考录音与转写；组件任务会在本机生成并验证运行引擎。
- 音色库支持管理情绪与场景参考录音、转写、语言和默认参考；情绪标记含多个可用档位时可调整强度，并可使用本地语速及音量控制。
- AnifLive 模型可在组件设置中下载、导入、重命名及删除；导入流程会先准备隔离运行环境，再继续模型转换与验证。
- 主语音推理的新默认模式改为 fast（快速）。设置中仍可切换 deep（深度）模式。
- AnifLive-TTS（本地语音合成）设置和组件管理整合；音色库可直接展开对应模型导入卡片并查看下载、转换和登记进度。
- 更新 DSH（后台执行宿主）适配后，流式思考隐藏开头的完整签名区块；普通回答正文保持显示。

## 修复

- 修复模型导入时选错辅助权重或参考录音、网页来源遗漏指定版本和子目录，以及下载短暂中断后不能继续的问题。
- 修复转换完成后模型未能登记启用、旧引擎因导出流程更新而被不必要地重建，以及参考音色试听或任务重试覆盖手动默认选择的问题。
- 修复情绪参考列表重叠、主音色卡片缺少基础参考播放器、转写保存未回写原条目及音色库导入入口定位错误的问题。
- 修复本地语音已返回部分音频后，后续合成失败仍被当作正常结束的问题；取消和模型切换时会按实际任务状态完成清理或恢复。
- 修复模型及运行依赖目录不可写时任务启动后才失败的问题；现在会在下载或转换前检查并说明无法写入的目录。
- 修复 AnifLive 通用基底在 Windows（操作系统）上的引擎导出验证和内存不足重试问题；通过实际加载及合成验证后才登记为可用。

## 升级注意

- 新设置及缺少运行模式的设置默认使用快速模式；已保存的快速或深度选择继续保留。选择本地语音时，需在组件设置中准备指定模型及 AnifLive 隔离运行依赖；在线语音选择继续按原设置生效。
- AnifLive 模型引擎在本机生成；需要兼容的 NVIDIA（英伟达）显卡，并预留足够的显存、内存与磁盘空间。首次准备可能需要较长时间。
- 删除 AnifLive 模型会同时删除其音色包及独占参考录音；共享录音仍会保留。删除前请在音色库确认需要保留的参考资料。
- 已登记的本地模型可能需要在组件设置中执行更新；使用 DSH 的用户需在组件设置中手动更新该组件，以启用新的流式显示适配。
