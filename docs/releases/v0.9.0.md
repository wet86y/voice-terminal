# Voice Terminal v0.9.0

Voice Terminal v0.9.0 is the first public source release and Windows distribution.

## Highlights

- Publishes the Apache-2.0 licensed Voice Terminal source and the Windows distribution installer.
- Adds in-app checks against the public GitHub Releases manifest.
- Downloads and verifies the installer with its declared size and SHA-256 digest.
- Hands the verified installer the current workspace identity, waits for the running product to exit, applies the existing transactional update, and confirms the new product window starts.

The installer preserves workspace user data, installed models, and runtime components while updating the application body.
