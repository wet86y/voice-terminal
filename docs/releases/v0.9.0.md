# Voice Terminal v0.9.0 首次公开发行

Voice Terminal 0.9.0 是项目首个公开源码版本及 Windows（视窗系统）分发版本。

## 主要内容

- 以 Apache-2.0 许可证发布 Voice Terminal 源码和 Windows 分发安装器。
- 在应用内检查公开 GitHub Releases（发行版）更新清单。
- 下载分发安装器，并按清单声明的文件大小和 SHA-256（文件摘要）验证内容。
- 将当前工作区身份交给已验证的安装器；等待运行中的程序退出后，通过现有事务更新程序本体，并确认新版窗口成功启动。

更新程序本体时会保留工作区用户数据、已安装模型和运行环境组件。
