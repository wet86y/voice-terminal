# Voice Terminal（语音终端）v1.1.0

## 新增与改进

- 统一主界面、设置、弹窗及启动维护页的按钮反馈：悬停轻微提亮，按下轻微加深与压下；开关反馈保持克制，减少动态效果时取消位移。
- 统一资源确认、版本提示、配对和图片查看弹窗的样式，长内容可独立滚动，窄窗口下操作按钮保持可见。
- “关于”页增加更新日志入口，按版本倒序显示摘要，点击展开完整内容；往期记录可离线查看。项目主页按钮统一为“GitHub主页”，更新卡片的四个操作按钮统一字号、高度、内边距与间距，宽度随文字自然变化并靠右对齐，同时精简说明。
- 在线和本地试音收到音频后即可开始播放；试听期间显示模型加载、连接、合成、播放及恢复阶段。
- 客户端的设备偏好、SSH（安全外壳协议）状态和配对操作集中在“远程配对”卡片，搜索位于右上角，配对码与连接按钮同排；客户端也可直接重命名。
- 服务端入站客户端使用统一连接卡片，支持断开和移除。普通断开保留配对资料并通知客户端暂停自动重连，由客户端手动恢复；移除清理该客户端的公钥授权，重新连接需要重新配对。
- 局域网广播在发布前检查必要组件和当前启用功能；本地功能尚未就绪时保持未广播，未启用的可选组件不影响广播。
- 设备连接页与侧栏统一名称及简短说明，采用通用设置标题样式、本地运行／远程配对二分选择和独立保存，统一滑块开关、页面宽度与简短状态；操作提示复用自动淡出的弹窗，客户端连接、入站客户端及刷新操作集中在对应卡片内，工作台以“远程配对”标明客户端模式。
- 设备名称默认显示基础随机名称，右侧可直接重命名并支持中文；客户端与服务端显示名称允许重复，连接列表会自动添加数字后缀区分，保留各自独立的设备身份与配对资料。
- 客户端自动发现已配对服务端的可连接状态；普通断开后可免配对码重新连接，断开时也可移除该服务端及本机保存的密钥、地址和配对资料。
- 入站客户端统一显示“已连接／在线／离线”，不再单独标记当前语音设备；已登记条目在服务端重启后仍保留，断开的客户端可通过局域网公告显示在线状态。
- “关于”页的外部调试授权统一为滑块开关，并移到页面底部。
- 已配对的远程客户端可通过“代理控制台”在本机浏览器打开服务端 DSH（代理执行宿主）原生网页，沿用其插件、设置、审批及附件处理；支持多个网页同时连接同一宿主。
- 优化远程代理控制台的连接复用，减少整页刷新和插件资源加载时反复建立连接造成的等待。
- Voice Terminal（语音终端）插件的模型和推理强度直接共用 DSH（代理执行宿主）全局配置；选项随宿主模型目录更新，新建语音会话使用同一选择。
- 已配对设备连接前会核对双方程序版本；版本不同时，可在程序内确认通过现有加密连接同步较新版本，更新完成后继续连接。
- 设备连接中的配置、SSH（安全外壳协议）准备、搜索、配对和连接共用进度条，随当前阶段更新；无法取得准确百分比时显示持续进行中的状态。
- SSH（安全外壳协议）下载或启动确认、设备配置修复确认及六位配对码改用程序内弹窗，可直接通过项目调试入口查看和操作；关闭配对码弹窗同时关闭配对监听。
- 局域网连接兼容微软系统自带版和已安装的独立版 OpenSSH（安全外壳服务），按已有服务的实际路径、配置和端口检查，避免重复安装。
- 增加代理调试模式，开发工具可直接查看和操作正式界面、调用业务接口，并通过已授权的 SSH（安全外壳协议）连接调试远端程序。支持自动识别控件交互状态和查询接口参数约束，采用标准控件及正式接口的新功能可沿用同一调试入口。
- 客户端设备页显示麦克风实际开启状态。
- 增加工作区清理入口，扫描可重新生成的缓存、已退役下载和临时任务文件，确认后按扫描结果清理。
- 精简远程连接检查，逐次业务请求直接使用已认证连接和受限网络规则，减少重复系统扫描造成的等待。
- 同一正式程序支持“本地运行”和“远程配对”。本地设备可按需开启局域网广播；客户端通过搜索发现服务端，输入六位配对码后连接。
- 远程配对后，产品支持的业务设置、凭据、组件和资源任务在服务端读取、校验、保存和执行。客户端导入文件时使用本机选择器并通过加密文件通道传送，由服务端现有流程处理。
- 在线语音可以直接在客户端播放；客户端还可选择原始或压缩音频传输。TTS（语音合成）参考音频可在客户端试听服务端已登记的素材。
- 远程配对时，后台协作面板会实时显示服务端代理的思考、工具调用、执行输出和待处理授权，可直接在工作台同意、连续同意或拒绝授权。
- 远程配对时的首音延迟改由客户端本机计时，不再受服务端与本机时钟差影响；实时通道断开时显示“—”。
- 远程设备桌面协作可将屏幕截图、图像和文件作为附件传回；大文件通过独立设备通道流式传输并校验。
- 后台代理可在用户授权后，对已配对且具备相应能力的远端设备执行桌面操作；结果未知时可查询原任务，避免重复执行。
- 远程音色库中的参考录音和情绪样音可直接在当前交互设备试听，并可停止播放。
- 设备设置新增“检查 SSH 服务”，显示微软 OpenSSH（安全外壳服务）的官方程序、有效配置和实际监听状态，并提供按需准备入口。
- 设备广播增加准备中、网关启动、公告发布、运行和失败状态，自动更新实际结果；首次网络规则配置合并授权，减少重复检查与等待。
- 设备设置和公钥登记任务会在切换页面后继续显示进度，阻止同一任务重复提交；首次进入时，运行模式不再等待较慢的 SSH 状态检查。
- 系统检查、桌面辅助及运行环境维护会按任务需要选择本机稳定的 PowerShell（脚本运行环境），尊重用户指定的解释器。
- 关闭局域网广播后保留已配对设备和网络许可；再次开启会先检查已有防火墙规则，规则可用时直接恢复广播。
- 需要修复系统设置时，程序在本次运行中复用已授权的维护进程；修复被取消或失败后停止自动重试。

## 修复

- 修复更新日志弹窗中的版本条目被压成横条、标题与摘要裁切，以及展开后难以阅读的问题；完整记录保持自然高度并可滚动查看。工作区清理清单同步减少重复滚动。
- 修复部分弹窗键盘焦点循环、关闭后焦点恢复及拖动跨过遮罩时误关闭的问题；处理中保留关闭限制，弹窗内日期、时间和星期选择面板可正常操作。
- 修复试听音频已合成完毕，却因额外处理长时间等待才开始播放的问题；本地试音不再等待样音保存、重新解码后才起播。
- 修复本地试音中途失败后部分音频仍继续播放，以及远端试听取消后待发送片段和播放事务未正确收尾的问题。
- 修复未安装本地组件的客户端无法切换本地运行、因而无法进入本机组件管理的问题。可先切换并下载或导入组件，广播仍须通过必要组件及当前启用功能的就绪检查。
- 服务端明确通过已认证连接确认配对失效时，客户端自动清理对应旧配对；主机密钥变化或一般认证失败会暂停连接，保留旧信任，待有效配对码验证后再替换。
- 修复客户端组件页显示部分进程内存、与服务端统计口径不一致的问题。客户端不再显示组件内存和显存，相关占用在服务端查看；组件下载和模型导入统一在服务端操作。
- 修复入站客户端连接状态的错别字，统一显示为“已连接”。
- 修复每次启动时，已过期的状态读取仍弹出“请求目标已变化”错误条的问题；启动交接后自动读取当前状态，实际操作失败仍会正常提示。
- 统一设备连接页的按钮高度、字体、间距和操作列对齐，调整广播滑块与 SSH（安全外壳协议）状态行的比例。
- 修复自定义服务端名称后，广播校验未识别名称字段而报配置异常的问题。
- 修复每次进入设备设置页或普通刷新时反复查询系统 SSH（安全外壳协议）状态的问题；系统检查仅在主动检查、开启广播或准备任务结束时执行。
- 修复离开语音设置或模型导入页、切换连接后旧试听或转写任务仍继续运行的问题；页面退出或目标变化后取消旧任务，并忽略迟到回执。
- 修复 DSH（代理执行宿主）计划任务在投递回执失败后可能重复提交的问题；已投递的同一次到期任务会被识别并跳过。
- 修复内部服务端口被占用或实际端口变化后连接失败的问题；受管服务使用系统分配的可用端口，并按当前实际地址连接。
- 修复 SSH（安全外壳协议）配对成功后，业务通道仍因系统登录会话不同而被拒绝的问题；连接失败时提供受限桥接返回的具体原因。
- 修复重新连接服务端失败后，状态刷新清除错误原因的问题；失败说明保留，连接按钮恢复后可以重试。
- 修复配对码自动复制等待剪贴板响应时，配对窗口无法关闭的问题；关闭弹窗后恢复操作焦点，迟到的复制结果不再覆盖关闭提示。
- 修复 SSH（安全外壳协议）下载较慢时，前台提前退出广播准备流程的问题；长时间等待及切换页面后继续跟踪，准备完成后接着应用原设备设置。
- 改善 Windows 官方 SSH（安全外壳协议）功能下载较慢时的等待处理，延长安装及状态回执的等待时间，页面长时间等待后仍继续跟踪后台任务。
- 修复开启局域网广播时可能跳过 SSH（安全外壳协议）下载确认的问题；依赖缺失时先说明官方下载及默认目录，确认并准备就绪后才保存广播设置，取消或失败时保留原配置。
- 修复已有 SSH（安全外壳协议）服务的自定义参数被忽略、端口冲突原因不清楚及公钥文件位置被直接推测的问题；无法核验的配置停止自动处理并显示原因。
- 修复多处界面同时修改设置后显示旧状态、迟到的读取覆盖新保存结果，以及单条指令修改覆盖其他条目的问题；设置结果以服务端为准，未保存的编辑内容继续保留。
- 修复代理调试连续请求时回执拥塞导致连接提前关闭、回执缺失却仍显示成功的问题；单次输入结束后会等待已接受请求完成并完整返回结果。
- 修复组件设置误显示 OpenSSH（安全外壳服务）历史失败提示，以及点击重试后报“不支持的资源编号”的问题；系统功能继续在设备与角色中管理。
- 修复本体更新已换入新程序后，旧文件短暂占用导致更新收尾和后续兼容检查中止的问题。
- 修复代理调试模式调用本机语音服务和发现部分远端文件、语音接口失败的问题。辅助技术现在能识别语音会话的开始、停止和等待状态。
- 修复远程客户端的悬浮窗无法从托盘显示的问题。
- 修复远程客户端选择音色参考音频时，文件选择窗口无法打开的问题。
- 修复跨设备长时间播报时播放缓冲溢出导致录音通道重连的问题。服务端按客户端扬声器储备调整发送，单轮播放故障只结束该轮播报。
- 修复跨设备播放异常后服务端长时间等待结算、设备进度回执被丢弃或关闭媒体通道的问题。客户端播放失败可以正常回报，后续语音输入仍可继续。
- 跨设备试听支持超过两秒的音频，并按真实输出进度结算。本机播放器停止或设备时钟停滞时，不会把未播放的音频计为已完成。
- 修复远程录制按钮在刷新服务端设置时反复禁用，以及旧状态覆盖停止结果的问题。开始录制后可以立即取消，界面收到音频后才显示正在录制。
- 修复服务端设备页遗漏已连接客户端，以及切换语音设备时原客户端一起断开的问题。连接、设备占用和录制状态会随服务端状态更新。
- 短暂丢失麦克风音频时保留媒体连接，持续缺少音频时显示采集恢复状态。

- 修复远程监听时采集缺口、迟到音频和短时拥塞引起的反复掉线及录音切换。短时缺口只中断当前识别输入，麦克风暂不可用时在客户端恢复采集。
- 修复远程配对后后台协作轨迹停留在打开页面时的旧快照、任务开始或出现授权请求时面板不更新的问题。
- 减少远程语音建连和开始监听的等待。连接已有可信时钟样本后继续后台测量，网络拥塞时停止和释放连接有明确等待上限。
- 修复停止监听后切换仍重新开启麦克风、切换失败导致无可用输入，以及组件重试后会话仍使用旧识别或音频处理对象的问题。
- 修复远端麦克风还在准备时提前报告开始成功的问题，客户端现在会显示等待采集。
- 改善本地语音构建中断后的重试及临时构建文件清理。
- 修复管理连接已建立，但任务和语音通道持续准备或超时的问题；服务端完成回执后正常结束桥接，无换行的数据及时传送。
- 修复局域网公钥认证成功后，管理及文件连接提前关闭、有效管理回执被误拒绝，导致客户端无法读取服务端就绪状态或继续使用的问题；等待数据时仍能正常停止服务。
- 修复底层连接仍存在、管理通道不可用时“断开”入口消失的问题，便于断开旧连接后重新配对。
- 修复管理员账户以普通权限运行时被误判，导致配对公钥登记位置错误、客户端无法通过 SSH（安全远程连接）认证的问题。
- 修复局域网已发现设备、配对码验证通过后，因工作区编号被误判而无法登记设备或建立连接的问题；配对失败后清除过期的授权进度提示。
- 修复远程客户端尚未配对、等待连接或服务端组件仍在加载时，被误报为本地组件故障的问题；组件页会显示对应等待状态，并在连接恢复后自动读取服务端状态。
- 修复服务端正常监听、思考或播报时客户端误报核心不可用，以及管理会话反复变更、长时间轮询后无法继续管理组件的问题；统一后台重连，主动断开后保持暂停，切换目标时丢弃旧回执。
- 修复广播开关触发整个语音服务重启、重复完整系统检查导致长时间等待的问题；同一轮检查与广播任务复用结果，显式检查仍可强制刷新。
- 修复广播已经运行时，获取配对码因读取系统主机公钥被拒绝而失败的问题；改为从本机运行中的 SSH（安全远程连接）服务取得公钥，无需修改系统密钥权限。
- 配对过期后释放配对认证材料与监听，退出后移除当前实例的启动快照，避免旧的就绪或失败记录被误用。

- 修复从语音设置跳转到 AnifLive 组件卡时，组件卡未自动展开的问题。
- 修复远程客户端误把组件安装、AnifLive 转换或设置保存落到客户端本机的问题；服务端连接异常时保留原目标状态，不将操作改投到本机。
- 修复 SSH 状态检查仅凭服务运行就报告就绪的问题；遇到非微软服务路径时会停止准备，避免启动来源未验证的 sshd（SSH 服务进程）。
- 修复远程客户端检查服务端 SSH（安全外壳协议）时，历史准备失败仍显示为当前故障的问题；服务已就绪时将其作为可展开的历史记录，服务未就绪时保留错误和重试入口。
- 修复升级后 DSH（代理执行宿主）插件加载清单未同步，导致设备控制服务缺失、代理反复启动失败的问题；保留已有用户设置。
- 修复进入设备设置或检查相关状态时弹出空白命令行窗口的问题。
- 修复首次开启广播时网络规则缺少端口而失败，以及网络规则失败被误报为 SSH 服务安装或启动失败的问题。
- 修复广播配置已保存但公告发布失败时开关显示与实际配置不同步，以及历史任务失败仍干扰当前就绪状态的问题。
- 修复顶层组件异常提示条未居中和设备开关排列不齐的问题。
- 修复 Windows 返回不同子网表示时广播规则被误判失败，并在失败清理中反复请求管理员授权的问题；补齐局域网多播设备发现规则。
- 修复系统自带 Windows PowerShell 5.1（命令行运行环境）下账户检查、受限公钥摘要计算和文件替换失败，以及中文或带空格路径的状态回执编码问题。
- 修复配对时服务端仍在等待管理员确认，客户端已提前超时的问题；广播发布、设备切换和维护交接会按同一任务状态协调，避免重复发布和旧进度回写。
- 修复关闭并重新开启广播时反复请求管理员授权，以及兼容程序更新后已配对连接因构建编号变化而失效的问题。
- 修复远程客户端查看设备管理信息后，后续核心状态与任务操作无响应直至超时的问题；管理请求改用独立连接，不再占用控制通道的会话标记。
- 修复远程语音通道偶发断开、长时间运行后时钟映射失效，以及监听反复启停时旧音频帧干扰新一轮识别的问题；时钟测量可重试，输入重新开始时与旧输入隔离。
- 修复停止远程语音播报后客户端仍继续播放尾音的问题；停止结果按设备实际输出进度结算。
- 修复媒体连接建立但语音核心暂未恢复监听时过早回退到本机的问题；单项能力暂不可用时优先恢复该能力，避免不必要地重启仍可用的语音接口。
- 修复设备重连期间已批准的桌面操作可能落到新连接的问题；操作派发会沿用批准时的设备连接，窗口动作只在批准后复核一次。
- 修复设备断开或不具备桌面控制能力时无法查询原任务的问题；执行结果未知时提供原任务编号，方便查看结果并避免重复操作。
- 远程任务通道状态现在会单独显示桌面控制能力及不可用原因。
- 增加客户端有界滚动运行日志，记录远程连接、媒体输入和恢复结果，便于排查设备连接问题。

## 升级注意

- 使用远程语音、设备附件、代理控制台、断开通知及配对失效同步前，请将客户端与服务端一并更新到本次程序。轻量设备客户端须使用对应客户端包单独更新；本轮发布的安装器用于完整程序。
- 首次使用局域网程序版本同步前，两端需先通过原正式更新入口升级；提供较新版本的设备须保留匹配的维护分发器，缺少时按程序提示准备。
- 本次采用新的设备授权格式，旧授权需重新配对一次；此前配对失败或公钥被拒绝的设备，也请在更新后重新获取配对码，并在服务端完成可能出现的管理员授权。此后兼容程序更新沿用原授权；更换局域网后需重新配对以更新来源子网。
- 普通断开保留配对资料，客户端可手动恢复连接；移除后需要有效配对码。离线或旧客户端无法收到已认证的失效确认时，仍需按提示重新验证。新连接私钥绑定当前 Windows（操作系统）账户，跨账户或设备复制数据后需重新配对。
- 共享主机需要微软 SSH（安全外壳协议）服务端；远程客户端自带连接能力，无需额外安装系统连接客户端或启用系统密钥代理。缺少服务时通过 Windows Update（系统更新）安装，需要联网和管理员授权；自定义公钥存储或无法识别的条件配置需先核对。
- 开启广播会检查必要组件、当前启用功能及局域网规则，确认需要系统修复时才请求管理员授权。关闭广播停止本程序局域网入口，保留系统 SSH 服务、已配对设备及受限子网规则；需收回网络许可时，请在设备设置中执行相应维护。
- 插件原先单独保存的模型与推理强度改为沿用 DSH（代理执行宿主）全局配置；已有或恢复的会话保留各自选择。在插件页修改模型会同步更新全局配置；断开连接、撤销授权或重启宿主后，请重新打开远程代理控制台。
- 远程模式中的模型、组件及资源任务由服务端处理；本轮远程页面暂不支持选择客户端本地 AnifLive（本地语音引擎）模型文件夹。首次试听尚未加载的本地模型仍需等待模型冷启动与参考音色准备，界面会显示当前阶段。
