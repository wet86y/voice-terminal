# Voice Terminal（语音终端）v0.9.8

## 新增与改进

- 语音助手可按当前对话语境继续倾听，在话题停顿时结合后续输入与后台状态自然衔接；持续次数有限，不会延长最终静默结束时间。
- 播报过程中可取消并替换当前内容：旧语音平滑淡出，新语音准备好后接续播放。
- 主人声纹筛选改为先核对约 1.2 秒首段，再按整轮判断；暂缓轮次连续三次确认主人后可恢复全文。设置页用开关控制筛选，四项参数移入默认折叠的高级区域，已保存的声纹模板默认折叠；“仅主人可打断”可单独启用。
- 热词页集中搜索、添加、导入、数量、词条和分页；列表在限定高度内滚动并适配窄面板，空列表会提示添加方式。

## 修复

- 修复取消完整性检查后可能影响有效启动状态的问题；必要收尾完成后可从原入口启动，正常取消不会显示为维护失败。
- 修复组件下载进度条填充高度不完整的问题。

## 升级注意

- 使用声纹筛选的用户请在更新后重新核对设置和筛选效果；若现有临时声纹权重大于 0.80，保存新参数前需先调至 0.80 或以下。
- 旧版当前会话的环境记录页已移除；未确认的拦截文本不再显示为独立环境记录，也不提供给语音助手读取。
