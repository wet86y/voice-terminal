# Voice Terminal（语音终端）v0.9.3

发布日期：2026-10-19。本版本修订“关于”页与工作区迁移体验，并统一应用更新和 GitHub（代码托管平台）资源下载的加速节点选择。

## 主要变更

- 设置页改名为“关于”，应用更新卡片移至第一项；工作区改为横向卡片，只显示工作区根目录，并通过“迁移工作区”执行选择、确认、迁移校验和切换。
- 应用更新安装包及 GitHub 发行附件、原始文件域名上的组件下载共用加速节点。下载时对原站和启用节点进行有限测速，按当前速度优先选择来源，来源失败时自动回退。
- 大文件在来源支持范围请求时复用 DesktopUpdateKit（桌面更新与下载组件）的四路分段下载；保留摘要校验、取消和连续断点续传。
- 更新卡片显示作者 `wet86y`，GitHub（代码托管平台）按钮打开当前项目仓库。

## 兼容与数据

更新过程保留用户设置、会话、模型、运行环境和组件登记。更新清单仍直连获取，安装器按交付记录校验大小及 SHA-256（完整文件摘要）。

本版本锁定的 DesktopUpdateKit 上游代码未修改；当前网络测速用于补充锁定原生版没有的来源速度比较。测速为下载前的有限样本估算，来源实际传输失败时继续自动尝试后续来源。

节点配置、回退规则和验证边界见[下载来源指南](../guides/download-sources.md)及[节点接入验收记录](../testing/github-node-selection-20261019.md)。
