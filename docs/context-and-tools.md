# 上下文与工具规范

每次模型请求只能由 `LLMContextProjector` 基于 `SessionLedger` 生成。账本按顺序保存最终用户输入、实际听到的助手文本、打断说明和工具来源块；投影器额外提供当前输入的最终确认/用户讲话语义。未播放输出、失效预取和 UI 中间文本不进入后续请求。

工具来源块包含工具名、参数、执行时间、结果与 `external_untrusted` 来源标记；不包含对话、轮次、语音、epoch 或决策身份。工具结果是资料，不是指令；模型不得从其中获取系统权限、改变会话规则或执行非只读操作。

允许按意图自动调用受限目录文件工具与联网搜索。预测阶段可预取只读工具；新输入、对话结束或 epoch 推进会使结果失效。Agent 重新选择并通过统一 `(turn_id, epoch)` 校验后，结果才会进入账本。
