# 程序升级与必需组件更新

程序本体与本地模型分别交付。安装新版程序会更新界面、业务代码及随包资源清单，保留工作区中的模型、运行环境和用户设置。新安装按当前清单安装最新组件；已安装组件的版本或文件内容与当前清单不同时，组件卡片显示“更新、导入、跳转”。任一组件缺失、不完整或待更新都会阻止整体语音服务启动，更新及校验完成后才恢复使用。

## 组件详情与更新任务

组件卡片显示待更新状态，详情展示当前版本及目标版本；展开详情会刷新资源状态。历史安装没有记录模型版本时，版本保持未知，不把当前目标版本当作已经安装的版本，也不提供旧版推理适配。管理页与运行中的组件页共用更新、导入及来源跳转入口，更新复用原有下载链路，缺失组件使用“下载”入口。

更新使用随包清单中的固定来源、文件大小及 SHA-256（安全散列摘要）。任务先在工作区暂存目录准备候选内容，已经安装且摘要匹配的文件可以复用，新增或变化的内容才需要重新获取。取消或校验失败会保留旧目录供恢复和重试，但旧组件不满足当前版本要求时不能启动服务。

进入切换阶段后任务不可取消。桌面宿主暂停原本运行的服务，释放模型文件占用，交换新旧目录并刷新资源登记。候选校验通过后提交当前组件；其他组件仍需安装或更新时，整体服务保持停止。全部必需组件就绪后才恢复此前运行的服务，最后一次切换保留备份至服务恢复检查通过。恢复失败则回滚模型和资源登记，并再次按全部组件的当前版本要求判断启动资格。原本没有运行服务的管理页不会因组件安装完成自动启动后台服务。

模型文件的完整性校验和服务入口就绪是不同检查。服务入口就绪不等同于所有模型都完成实际音频推理；真实模型的流式输出及内存占用另由推理验收覆盖。

## 模型版本登记

每个新安装的模型目录包含 `resource-install.json`（模型安装收据）。收据记录安装时的版本及文件摘要，根模型清单继续供工作区完整性检查使用。旧安装没有收据时，读取 `models/manifest.json`（模型根清单）中的对应记录识别待更新状态；启动与更新校验始终以当前随包清单为准，文件损坏仍报告不完整。

| 字段 | 中文说明 |
| --- | --- |
| `update_available` | 已安装模型、代理组件或语音运行依赖是否必须更新，待更新状态会阻止整体语音服务启动 |
| `installed_version` | 已安装模型或代理组件版本；旧安装未登记时为空 |
| `version` | 模型与代理行表示随包目标版本，语音服务行保留解释器版本含义 |
| `resource_id` | 模型资源稳定编号 |
| `content_sha256` | 收据内排序文件记录的内容摘要，不包括版本号或收据自身 |
| `files` | 已安装必需文件及实际存在的可选文件 |
| `path`、`size`、`sha256`、`optional` | 模型内相对路径、字节数、文件摘要和可选标记 |

同版本号的必需文件变化也会触发更新。当前清单的必需文件必须全部安装并校验；曾安装的文件被新版清单移除时，会在更新事务中清理。整个旧目录在成功切换后删除，避免遗留已不再使用的权重或文件。界面盘点使用收据与文件大小进行快速检查；正式服务启动和更新后的恢复会再次读取文件并核验完整摘要，同长度的内容损坏也不能绕过启动检查。

启动盘点已经确认有缺失、待更新或运行依赖未就绪的组件时，直接进入管理页，不继续扫描这些旧组件的全部文件。全部组件满足当前清单后才执行启动的全量摘要复核；该顺序避免更新前重复读取大量旧文件，也保留更新后和正式启动前的完整性门槛。

## 四项内存优化的交付

前三项由新版程序代码直接生效：使用 `mmap`（文件内存映射）加载权重并消除重复权重复制；按实际模型精简 FunASR（语音模型运行框架）导入；及时释放说话人功能不再使用的临时模型实例。模型加载改动受固定运行库版本及源码摘要保护，未知组合保留原加载路径。

第四项是处理器运行模式下的未量化 ONNX（开放神经网络交换格式）语音活动检测。经过数值和流式输出对照的导出资产随程序携带，作为 FSMN-VAD（前馈序列记忆语音活动检测）模型资源的新版本交付；模型更新时安装到模型目录，并补齐对应运行依赖。完整语音环境包含新的轻量检测依赖组，缺少这些依赖时必须配置完成后才能启动整体服务；配置器复用已验证的相同包，补齐缺失内容。

固定摘要的随包模型资产按原始字节提交，避免 Git（版本管理）在 Windows（操作系统）上自动转换配置文件换行而改变摘要。资产清单包含字段中文说明，资源目录中的大小及摘要与实际资产一致。

新版 `policy_schema: 2`（资源策略格式版本）默认采用 `auto`（自动选择），在处理器模式下优先使用校验通过且运行依赖就绪的轻量模型。受管配置未声明当前格式时，后端采用新版默认，线程、音频及历史字段继续读取；读取过程不改写现用用户文件。当前格式下的明确后端选择和自定义策略路径继续有效，图形处理器运行偏好保留。模型和运行依赖的启动门槛始终按当前随包清单检查。

原 `model.pt`（浮点权重文件）仍属于新 FSMN-VAD（语音活动检测）资源的有效文件，用于图形处理器运行和轻量路径故障回退。它与更新完成后删除的旧目录备份作用不同。SenseVoice（语音理解模型）量化候选和说话人限线程候选没有通过本轮默认启用门槛，继续保持原默认。

验证依据见 [内存优化报告](memory-optimization-20261010.md)。正式产物仍以 `build`（构建编号）区分，在线自动更新另由项目的分发接入完成；本功能针对用户安装新版程序后完成必需组件更新。
