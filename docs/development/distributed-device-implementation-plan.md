# 分布式运行实施跟踪

本文件跟踪 [分布式设备运行架构与开发顺序](../architecture/distributed-device-runtime.md) 的新一轮产品化实施。目标是同一正式程序支持“本地运行”和“远程配对”，完成受保护的局域网发现、服务端管理界面、真实语音切换和同机独立工作区验收。

## 2026-11-20 高频附件传输

- 远端双图采集使用客户端原生截图和受限 FILE（设备文件通道），截图与播报控制分别领取任务。截图任务回执仅保留票据、摘要和裁剪信息。
- DSH（代理执行宿主）读取截图和已有会话图像时直接接收原始字节。已暂存的设备文件从逐块读取改为一次二进制流，完整长度与摘要匹配后才交付附件引用。读取结束或连接中断时释放读句柄和暂存票据。
- 回环附件接口在服务端和 DSH 插件同步升级时一次切换。控制连接和实时音频的传输安排见[高频截图与文件附件](../architecture/distributed-device-runtime.md#高频截图与文件附件)。
- 后端与插件回归覆盖超过 3 MiB（兆二进制字节）的设备文件单次读取、双图分段到达、摘要不匹配、取消和暂存票据清理。本机受限 SSH（安全外壳协议）回环验证覆盖截图执行期间独立领取播报停止。正式包更新及双机并发录放音、截屏和文件读取的延迟仍待验收。

## 已锁定的产品决定

- 本地广播默认关闭；本次验收用 `--mode local --broadcast on` 明确开启。
- 远程端保存配对信任并自动重连；被新客户端接管的旧客户端暂停自动重连。
- 服务端没有就绪客户端、客户端断线或关闭广播时，核心协调器显式切回本机；旧任务和播放不能自动改投或重放。
- 客户端在线语音使用服务端供应商凭据，经已认证连接临时下发到原生内存，在客户端直接合成播放，不传回音频。
- 连接后的业务设置、凭据、组件、资源任务和状态全部属于服务端；服务端现有校验、保存、组件事务和回滚逻辑仍是权威实现。
- 客户端在配置音色时选择音频文件，通过受限 FILE（文件）通道传到服务端并由服务端现有流程登记。完整 AnifLive（本地语音引擎）模型目录的客户端本地导入/转换不属于本阶段验收；模型资源通过服务端可访问的在线 URL（网址）下载并导入。
- Windows 使用微软官方 OpenSSH Feature on Demand（按需功能）及 Windows Update 安装，采用当前账户；必要时通过 UAC（用户账户控制）申请管理员授权。不创建新账户。
- 本期正式入口根据参数选择模式，但继续打开桌面界面。真正无界面 CLI（命令行入口）暂缓。
- 本期不验收客户端补齐本地组件后转本地运行，不做公开发行或公网组网。

## 已实施代码节点

### 节点 1：配置版本与启动选择（代码已接入；现场验收部分完成）

- device_config.rs：设备配置包含运行模式、广播、在线语音本地播放、压缩和重连暂停字段；旧角色保留为后端兼容投影。
- 第 2 版配置读时映射：standalone（独立运行）→本地且广播关闭，shared_host（共享主机）→本地且广播开启，remote_client（远端客户端）→远程。
- 正式启动解析接受 --mode local|remote 和 --broadcast on|off；远程模式拒绝同时启用广播。
- Tauri 正式入口将显式参数覆盖保存到受管设备配置，并按广播意图决定是否启动回环设备网关。
- compatibility::migrate_device_runtime_config 在原生启动时归档有效旧配置并迁移至第 3 版；远程旧配置不沿用旧主机信任，要求重新配对。
- 远程模式绕过本机语音组件和凭据门禁，不启动本机 Python 核心；模式切换进入协调流程。
- 旧覆盖版本 A 曾完成一次 local→remote→local 切换并恢复七项本地能力；最新 product-54 已完成本机覆盖和正式程序启动，当前保存模式仍为 remote/remote_client/broadcast=false。窗口状态为等待服务端连接，组件设置页提示远程管理不可用。尚未在最新构建上验收本地模式、广播或真实远程业务。

### 当前轮次增量记录（2026-11-17 至 2026-11-18）

- `DeviceConfig`（设备配置）已对外序列化为第 3 版 `paired_host` 字段；旧 `host` 只作为兼容输入，旧共享主机继续保留广播意图，旧 Opus（有损音频压缩编码）选择映射为压缩开启。
- `OpenSshServerStatus`（OpenSSH 状态）现在分别报告微软签名程序路径/版本、有效配置、sshd 实际监听端口、SID 解析的 SSH 登录名、当前授权公钥路径、项目规则有效性及其他已启用 SSH 入站规则；单凭服务运行不再判为就绪。
- `--mode local|remote` 与 `--broadcast on|off` 完成参数校验；单实例收到显式模式参数时会调用协调流程，不只聚焦旧窗口。
- 本地广播已连接服务专用 TCP 入站规则和 mDNS 公告；开关开启前先检查官方 SSH、用户账户和规则，检查按钮在已就绪时只读返回，未就绪时经用户确认进入受管安装任务。
- 设备配对窗口由原生 `PairingCodeWindow`（内存配对窗口）管理；服务端获取码时返回一次六位码，页面自动复制。客户端只从最近一次 mDNS 结果选择目标，PAKE 认证后接收并校验 SSH 主机公钥，原生写入客户端配置和本机凭据库身份引用。
- SSH 授权公钥脚本只维护带工作区/设备标记的行，写入 `restrict`（受限密钥）、精确 LAN `from`（来源范围）和固定强制命令；授权文件权限不合规、SID（安全标识符）不匹配或 Entra 账户均拒绝修改。
- `ssh_device.rs` 的控制和媒体请求使用固定 `exec`（远程执行）标记；文件请求另走固定 FILE（文件）桥接标记和独立回环监听器，仍校验工作区、SID（安全标识符）、程序构建、广播状态及设备信任。该通道只接受登记的受限文件任务，不开放任意路径或用旧 SFTP（安全文件传输协议）流程绕过票据和摘要核验。
- Tauri 测试 SSH 服务已同步改为接受固定控制/媒体 `exec` 标记，并且只接各自动态分配的回环产品网关端口，支持并行运行而不争用正式默认端口。
- `/v1/management`（远程管理入口）分为独立原生管理操作和核心业务代理：`management.status`（管理状态）、资源任务及 `system.ssh.*`（SSH 系统功能）由不依赖 Python 核心的原生管理服务处理；产品业务操作仍经固定白名单调用服务端 Python 核心处理器，并校验目标和任务连接代次。两条通道都拒绝任意网址、路径或未登记操作；核心业务代理仍不能在语音核心不可用时提供全部产品功能。
- 新增热点词 JSON（结构化数据）导入/预览、TTS（语音合成）音色管理、固定 TTS 任务及 AnifLive（本地语音模型）参考任务等远程操作白名单。音频文件不走普通远程过程调用；独立 FILE（文件）通道现支持经票据授权的来源清单上传、分块摘要核验及服务端提交，仍不允许客户端扫描或提交未授权路径。
- 产品页在远程模式下通过固定 SSH 管理操作读取服务端宿主快照并持续刷新；显示“正在管理”服务端、管理连接状态及独立的语音核心状态。开始/停止、重置/清空与推理模式切换调用服务端现有核心逻辑；业务请求保留目标服务端及会话代次校验。远程未知 API（业务接口）操作继续失败关闭，不回落到客户端本机 HTTP。

## 当前正式启动参数

```powershell
VoiceTerminal.exe --mode local --broadcast on   # mode（运行模式）为本地；broadcast（局域网广播）开启
VoiceTerminal.exe --mode local --broadcast off  # mode（运行模式）为本地；broadcast（局域网广播）关闭
VoiceTerminal.exe --mode remote                 # mode（运行模式）为远程配对，不启动本机语音核心
VoiceTerminal.exe --exit                        # 沿用正式退出流程
```

参数选择会保存至本机设备运行配置并进入正式桌面流程。最新 product-54 已从统一程序包覆盖本机并启动；当前窗口处于 remote 模式，显示等待已配对服务端连接，业务状态不可用。零组件 B 的远程产品页挂载已单独验证；本机真实发现、配对和服务端业务操作尚未验证。
