## 固定实现与来源

上游固定为 v1.5.0-beta，提交 `9bc349d3a71362b3bfdccbc630983809800954fd`。来源见[官方说明](https://github.com/Hiruynk/AnifLive-TTS/blob/9bc349d3a71362b3bfdccbc630983809800954fd/README_ZH_CN.md)、[官方转换器](https://github.com/Hiruynk/AnifLive-TTS/blob/9bc349d3a71362b3bfdccbc630983809800954fd/src/aniflive_tts/converter.py)。转换退出成功只说明命令完成；本项目另外执行九个引擎加载、中文合成及 48／96 标记分块流式验证。

补丁权威为 `voice_terminal/tts/aniflive_native.py`（固定源码准备模块），当前修订为 3。官方归档 SHA-256（内容摘要）为 `67929fedc70df998a6006028b6385743611c5d5a78a5ede3b6713f64435eada2`。每处替换检查官方原文件摘要，准备后保留完整源码文件清单和补丁前后摘要；不接受摘要不符的任意本机源码。

| 补丁 | 审阅决定与边界 |
| --- | --- |
| HuBERT（语音编码器）导出 | 导出前显式转单精度；保持上游数值容差。线程数使用项目资源策略，未恢复测试分支的固定 24 线程。 |

| 中文模型路径 | TensorRT（推理引擎）解析计算图时临时分配英文盘符别名。检查目录及全部外部张量引用，互斥分配，只撤销本任务创建的映射。 |

| 共享资源目录摘要 | 按相对 POSIX（可移植路径格式）字符串排序，避免 Windows 路径比较顺序改变官方目录摘要。 |

推理依赖锁为 `config/runtime/aniflive-runtime.lock.json`（运行与导出双角色固定依赖）。推理使用 PyTorch（张量库）2.10.0+cu128、TensorRT 11.2.1.2、Transformers（语言模型工具）5.5.0；仅导出子进程覆盖为 Transformers 4.51.3 及配套分词依赖。入口关闭环境自动路径处理，显式装配目录，不注入全局 `.pth`（路径脚本），不引用测试仓库。主语音环境保持独立。

盘符映射属于 Windows（操作系统）登录会话，强杀进程不会自动撤销，依据[微软说明](https://learn.microsoft.com/en-us/windows/win32/fileio/defining-an-ms-dos-device-name)。因此映射前先写随机 `.pending`（未发布收据）文件并落盘，再原子发布最终收据。收据包含进程编号、创建时间与精确目标；父宿主结束子进程树后和下一次任务开始时，只回收失活且目标仍精确匹配的映射。写入中断不会发布空收据，活动或无权检查的进程与目标不匹配的映射均不删除。真实强杀、发布前强杀及错误目标保护已有自动测试。

共享输入另由 `config/runtime/aniflive-shared-assets.lock.json`（共享资源固定锁）登记 11 个文件，大小来自已通过官方内容摘要的本机输入。模型、fastText（语言识别模型）及 NLTK（语言资源）归档统一使用可续传、重试和摘要校验的下载任务。缓存准备不改现用共享文件；宿主释放冲突占用后离线启用并核对词典目录摘要，不依赖上游直接联网解包入口。导入的低采样率参考录音同样保留原始采样率。

## 可复跑入口

正式程序的组件列表与以下非交互入口调用同一配置任务；分发器不下载组件。下列命令在源码根目录执行。

```powershell
# 准备隔离运行依赖及固定官方兼容源码。
.\.local\runtimes\python\python.exe -B -X utf8 scripts/install-aniflive.py --prepare-runtime
# 从固定原始输入转换、真实验证并登记；不会改变播放目标。
.\.local\runtimes\python\python.exe -B -X utf8 scripts/install-aniflive.py --prepare-runtime --preset tangyuge-v2pp-d78cf598 --convert
.\.local\runtimes\python\python.exe -B -X utf8 scripts/install-aniflive.py --prepare-runtime --preset minimax-female-shaonv-zh --convert
# 外部配对权重导入；文件中使用下表七个字段。
.\.local\runtimes\python\python.exe -B -X utf8 scripts/install-aniflive.py --prepare-runtime --input-spec <规格文件路径> --convert
```

| 导入字段 | 中文说明 |
| --- | --- |
| `model_id` | 安全的英文小写模型编号 |
| `name` | 显示名称，1～80 字 |
| `gpt`、`sovits` | 成对语义权重及声音权重路径，首版仅支持 V2ProPlus（模型族） |
| `reference` | 3～10 秒参考录音路径，保留原采样率 |
| `reference_text` | 准确转写文本，不是文本文件路径 |
| `reference_language` | 参考语言，如 `zh`（中文） |

规格文件最大 1 MiB（兆比字节），拒绝额外字段、链接及越界路径。权重采用安全的仅权重加载，不自动开启不安全反序列化。通用底模元数据修正仅接受固定官方权重摘要，并校验处理前后全部张量摘要相同。

输入缓存位于 `.local/cache/aniflive-tts/inputs`（可复用原始输入），共享语言资源位于 `.local/models/aniflive-tts/shared`，不可变引擎版本位于 `.local/models/aniflive-tts/packages/<模型编号>/<版本>`。引擎版本由输入、补丁、依赖锁、桥接实现、设备及构建参数共同确定；实际生成文件使用本机摘要，不向不同机器指定统一引擎摘要。兼容规则继续遵循 [NVIDIA（英伟达）引擎兼容说明](https://docs.nvidia.com/deeplearning/tensorrt/latest/inference-library/engine-compatibility.html)。

隔离运行／导出依赖采用双目录恢复事务；模型包、模型总清单、应用登记及模型版本注册共用现有模型安装事务。失败、取消及未知错误不登记可用，不覆盖原播放选择。

上游计算包严格拒绝清单之外的文件，因此 AnifLive（本地语音）使用 `application-receipt.json`（应用验证收据）和模型版本登记，不再向包内额外写入通用 `resource-install.json`（组件安装收据）。同时包含两套收据会形成摘要循环或使服务拒绝加载。最终候选在登记前再次执行官方完整摘要清单检查；对应事务回滚和登记后文件集合已有回归。首次暴露该冲突的 `3c5d3b83595770eede7a6bed`（诊断版本）不可视为当前可用版本。

## 已发现的真实限制与诊断分类

通用中文少女基底在本机的 `GPTEncoder_seed_1_24`（语义编码器固定种子样本）导出数值校验失败：4 线程资源策略下，键缓存 39 个、值缓存 34 个元素超出上游 `rtol=1e-3`（相对容差）及 `atol=1e-5`（绝对容差）。最大绝对差分别约 0.0001283、0.0000903。多种计算后端和线程组合诊断未得到可靠修复；24 线程个别运行通过不足以证明可靠。本轮不降低容差、不重新固定 24 线程、不复制测试分支引擎，也不登记此模型为可用。原始现场位于 `.local/tmp/aniflive-tasks/m-mgivcce5`，补充诊断位于 `m-skzrz_8c`。因此两款模型均可用、双模型正向互切等验收尚不能宣称通过。

唐语歌首次实际转换已完成九个引擎及独立进程完整／流式执行。SoVITS（声音还原模块）构建中的 Myelin（TensorRT 内部模块）流捕获报错均紧邻明确的“不支持图捕获，改用普通执行”日志；成功序列化后真实执行通过。分类器仅接受这种明确回退并同时具有完整执行证据的情况；未知错误、实际加载错误和执行错误仍阻止登记。完整首次现场为 `.local/tmp/aniflive-tasks/m-daldafy6`；后续最终重跑与登记结果以本机报告为准，不以此文档代替运行收据。

最终配置已验证通用权重导入入口的相同输入复用，以及唐语歌 48／96 标记分块各自的真实输出。唐语歌最终构建任务为 `.local/tmp/aniflive-tasks/m-kyuvtgth`（本机构建现场），登记版本为 `7f6d9e7323d4bfb5a0b69cac`（不可变本机构建版本）；通用基底最终任务 `.local/tmp/aniflive-tasks/m-rysdd03v`（严格导出验证现场）仍数值校验失败，未登记为可用。完整结果见[本地整合与验收报告](../testing/aniflive-local-integration-20261107.md)。诊断资料保留在受管本机目录，源码文档不收录完整大日志和模型。

主线相关测试将旧分发门禁迁移为新模型的精确版本、损坏拒绝、固定原始输入和旧资料保护行为；旧后端专属源码测试仍只作历史参考，不能据此重新启用旧运行程序。旧补丁制作、质量构建及原生资源迁入脚本已经移除，旧后端提供器不进入正式程序包。

## 主线行为与交付边界

设置格式为 20；`backend`（语音后端）仅允许 `minimax`（在线）与 `aniflive`（本地）。本地默认编号是通用基底，实际播放目标最终保持 MiniMax。浏览设置与保存播放目标继续分离。旧音色、录音及用户资料不迁移删除。

AnifLive 音色库下提供显卡高性能、48／96 语义标记分块、首块到达后 0～200 毫秒等待。高性能关闭事件预热；活动回答和续写持有参数及参考快照。流结束仍核对服务端会话及全部已提交文本段的终态，不能把部分音频后的服务端失败视为成功。服务使用自动回环端口、工作区认证与受管进程生命周期。

资源归属沿用 `local-tts`（本地语音进程组），以进程编号和创建时间同时确认身份，递归归属子进程；读取实际常驻内存、私有提交量及系统专用显存计数。未知值保留未知，模型卡片只归属实际驻留模型。

旧权重退役仅允许固定两份 VoxCPM（旧模型）权重及其已确认收据和总清单条目；使用本体升级的仅删除事务，未知内容保留并报告。旧运行目录、用户资料、音色和滚动备份不在删除范围。源文件修改和单元验证不代表已完成本机覆盖；实际构建及覆盖结果须另记本机交付报告。
